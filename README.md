## 客户可用功能

- 产品系列浏览
- 型号关键词查询与可分享深链接
- 产品视频
- 规格书在线查看与 Word 下载
- 型号弹窗邮件询价
- 选型需求表单（仅在浏览器本地整理内容并打开邮件客户端，不上传表单数据）

## 数据质量

`tools/check_product_data.py` 为只读检查器，用于报告空型号、空产品名、疑似文件名误识别为型号以及重复型号。它不会自动删除或修改产品参数。
