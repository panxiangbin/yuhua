## 一、这次任务为什么会很长

这个网站面对的用户不是只会输入标准术语的人。  
真实用户会这样搜：

- `G2`
- `圆弧`
- `快移`
- `刀长`
- `撞机`
- `报警1001`
- `1815`
- `铝件转速`
- `对刀`
- `工件零点`
- `攻丝底孔`
- `主轴不转`

所以搜索系统真正需要的不是几组别名，而是：

1. 口语化搜索词
2. 行业俗称
3. 误写法
4. 简写法
5. 新手问句
6. 现场问题句
7. 材料/刀具/工艺混合查法

你这次要做的是一整套“搜索语言样本库”，不是几页示例。

## 五、每一组样本必须用固定结构

你必须严格使用下面结构，不能有的条目写全、有的条目只写一半：

### 样本结构

1. 原始搜索词
2. 标准术语
3. 类别
4. 扩展词列表
5. 用户类型
   只能写：`新手 / 操机员 / 编程员 / 工艺员 / 通用`
6. 搜索意图
7. 为什么要收录

示例格式：

```text
原始搜索词：快移
标准术语：G00 快速定位
类别：G代码
扩展词：G00、快速移动、空走、快速定位
用户类型：新手
搜索意图：想知道机床快速移动指令是什么
为什么要收录：这是新手高频口语词，不懂G00的人会直接搜“快移”
```
