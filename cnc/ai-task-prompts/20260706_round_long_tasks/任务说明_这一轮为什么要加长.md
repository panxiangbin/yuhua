# 这一轮任务说明

这次 `0号 / 3号 / 4号 / 5号 / 6号` 的任务，整体都被刻意加长了。

原因不是为了凑字数，而是为了修正前几轮的两个问题：

1. `5号` 和 `6号` 的任务偏纯文字研究型，网页版 AI 很容易几分钟内交一份“看起来很多”的长文。
2. `3号` 和 `0号` 虽然能落本地，但上一轮已经证明：有文件不等于可直接接入，还必须把合同、校验、结构统一做完。

所以这一轮的任务设计原则是：

- 任务体量更大
- 字段和格式约束更严
- 明确要求产出可被 Codex 二次消费
- 明确要求统计、验证、自检
- 明确要求把“研究内容”和“可接入内容”分开

这一轮最重要的目标不是“快”，而是：

**让每个 AI 在自己最擅长的线上，产出更难糊弄、更难水掉、更方便后续真正落地的结果。**
