每个条目补充这些字段：

```js
quickCheck: [
  '检查项1',

  '相关知识点ID2',
  '相关知识点ID3'
],

```

### 字段要求

#### quickCheck
必须是现场加工前能实际检查的内容，不要写空泛句子。

错误示例：
```js
quickCheck: ['检查是否正确']
```

正确示例：
```js
quickCheck: [
  '当前坐标系是否确认为 G54？',
  'X/Y 零点是否和图纸基准一致？',
  'Z 零点是否单独确认过？',
  '程序起点是否处于安全高度？',
  '首件前是否执行过单段或空运行？'
]
```

#### toolIds
只允许使用以下ID：

```text
speed           转速计算器
feed            进给计算器
surface-speed   线速度计算器
unit            英制 / 公制换算
roughness       Ra / Rz 粗糙度换算
```

#### params
只给确实有参数价值的知识点补。比如：

- 转速 → diameter / vc
- 进给 → rpm / flutes / fz
- 粗糙度 → ra / rz
- 英制换算 → inch / mm

坐标系、回零这类不适合参数联动的条目，`params` 可以不写。

#### relatedIds / nextId
必须引用真实存在的条目ID，不能编造不存在的ID。
