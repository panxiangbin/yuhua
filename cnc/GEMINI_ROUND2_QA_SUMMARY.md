## 三、 42307 物理文件与 42294 索引条目的差额成因

差额共 **13** 个，构成原因如下：
1. **物理扫描排除了 19 个文件**：
   - 包含根目录下的 `README.md` (1个)。
   - 包含以 `_` 开头的临时文件和测试脚本 (7个)。
   - 包含非 Markdown 图像资源或调试中间件 (11个)。
2. **索引在内存中额外模拟了 6 个条目**：
   - 物理 `06_考证职业` 下实际文件数是 **40,440** 个。
   - 内存模拟题库为满足前端页面整卷及性能适配，生成了 **40,446** 个虚拟条目（多了6个占位条目）。
3. **最终数学恒等关系**：
   $$\text{物理文件数 } 42,307 - \text{剔除 } 19 + \text{模拟增量 } 6 = \text{索引总数 } 42,294$$
