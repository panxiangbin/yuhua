## 设计理念

### 1. 色彩心理学
**土黄色系选择原因**:
- 大地色系传递稳定、可靠的专业感
- 低饱和度暖色减少视觉疲劳
- 适合长时间查阅资料的工作场景
- 符合"数控工程师工作平台"的专业定位

### 2. 移动端优先
**横向滑动设计**:
- 露出"半张卡片"的视觉暗示
- 符合手机端用户的滑动习惯
- 比网格布局更节省垂直空间
- 12px间距适合手指触控（避免误触）

### 3. 微交互设计
**按压反馈**:
- `:active`状态轻微缩放
- 给予即时的触觉反馈
- 提升操作确定性

## 技术细节

### 1. 滚动条隐藏
```css
scrollbar-width: none; /* Firefox */
::-webkit-scrollbar { display: none; } /* Chrome/Safari */
```

### 2. 文字截断
```css
display: -webkit-box;
-webkit-line-clamp: 2;
-webkit-box-orient: vertical;
overflow: hidden;
```

### 3. 响应式断点
- 768px：平板和小屏笔记本
- 375px：iPhone SE等小屏手机
