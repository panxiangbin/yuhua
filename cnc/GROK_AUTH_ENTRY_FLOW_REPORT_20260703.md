# GROK_AUTH_ENTRY_FLOW_REPORT_20260703.md
**数控网站授权访问入口设计报告**  
**日期**：2026-07-03  
**重点**：用户体验导向的授权进入流程

## 1. 公开区与授权区的边界建议

**公开内容**（所有人可见）：
- 基础G代码/M代码速查表
- 常见报警代码简单解释
- 新手学习路线概览（目录级）
- 基础参数换算工具（简单版）
- 公开宣传页、关于我们、联系方式

**授权内容**（需授权后可见）：
- 完整工艺参数库（详细切削参数、刀具推荐）
- 高级G代码案例 + 子程序模板
- 完整学习路径 + 视频/图文深度资料
- 专有报警排查案例 + 内部经验总结
- 未来可能添加的付费/会员专属资料

**分界理由**：
- 公开区降低门槛，让新手能快速试用，建立信任和传播（符合“不能一上来就把所有人都挡住”）。
- 授权区保护核心价值内容，避免免费泄露，同时给管理员控制“谁能看更有价值资料”的能力。
- 这种分层符合数控用户心理：先免费尝鲜，再通过价值决定是否申请授权。

## 2. 首次访问流程设计

**新访客首次进入流程**：
1. 进入首页 -> 看到公开区内容 + 顶部/侧边“探索高级资料”提示卡片（不弹窗）。
2. 浏览公开内容时，遇到授权内容链接 -> 显示“预览卡片 + 申请查看完整版”按钮。
3. 点击后 -> 进入轻量授权页（非全屏拦截），提供“输入邀请码”或“一键申请”入口。
4. 成功授权后 -> 跳转回刚才内容，并显示“已解锁”小徽章。

**已授权用户进入流程**：
- 首页直接显示“欢迎回来，[昵称]” + 授权内容快捷入口。
- 所有授权内容正常显示，无任何提示。

**被分享链接进入流程**：
- 点击私密链接 -> 如果已授权，直接显示内容。
- 如果未授权 -> 显示“此内容需要授权” + 简单输入邀请码/登录框（保留原链接参数，授权后自动跳转）。

页面提示原则：始终友好、非强制，强调“解锁更多实用资料”。

## 3. 手机端授权入口建议

- **位置**：页面右下角浮动小按钮（“解锁高级内容”），或内容区内自然出现的“查看完整版”链接。
- **方式**：局部引导更好（绝不整页拦截）。点击后侧边抽屉或底部弹层显示授权选项。
- **最不影响传播和试用**：用户可以随意浏览公开内容和预览，授权仅在想看深度资料时出现。手机端优先“邀请码输入”+“一键申请”按钮，操作不超过2步。

## 4. 三种方案对比

| 维度 | 邀请码 | 邮箱授权 | 私密访问链接 |
|------|--------|----------|--------------|
| 对普通用户的理解成本 | 低（输入一串字符） | 中（需要邮箱验证） | 最低（点链接即可） |
| 对手机端的便利性 | 高（输入框友好） | 中（需切换邮箱App） | 最高（直接打开） |
| 对管理者的维护成本 | 低（生成/禁用码） | 中（管理邮箱列表） | 低（生成一次性链接） |
| 对内容保护的强度 | 中（码可能泄露） | 高（可追踪用户） | 中高（链接有时效） |

## 5. 最终推荐

**最推荐方案**：**私密访问链接 + 简单邀请码作为补充**（混合轻量方式）。

**为什么最适合现在**：
- 手机用户多，点链接最自然、不打断浏览体验。
- 公开区+链接分享能很好平衡传播和保护。
- 管理员生成链接/码成本低，适合当前阶段内容逐步增加的场景。

**为什么不优先选另外两种**：
- 纯邀请码：理解简单但分享不便。
- 纯邮箱授权：流程稍重，手机端切换App麻烦，初期会吓到新用户。

**以后升级路线**：
- 初期用链接+码 -> 中期增加邮箱/微信登录 -> 后期接入简单会员系统（可选付费内容）。

此设计核心是**让用户先爱上公开内容，再自然申请授权**，最大化试用和转化。
