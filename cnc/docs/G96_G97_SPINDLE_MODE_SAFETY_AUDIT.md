# G96 / G97 恒线速与恒转速安全边界审计

> 审计基线：`main@f6523122950c23113cce4598dfa853cdac11656a`（PWA33 / learning33）  
> 审计范围：仅 CNC 新手训练平台。本文是改造验收依据，不是可直接上机的加工参数或程序。

## 1. 审计结论

当前基础 G/M 目录中的 G96 / G97 表述对零基础用户存在“把特定车床控制器语义误记成跨系统通用口诀”的风险，优先级为高。

当前基础条目中可见以下容易被直接照抄的表达：

- G96：把“用 G96 前先用 G50 限制最高转速”写成无控制器范围的通用做法，并给出固定 `G50 S2000；G96 S180` 数值示例。
- G97：把“G97 后 S 就是转/分”写成无控制器范围的通用结论，并给出固定 `G97 S800 M03` 数值示例。

这些句子在部分车床控制器上可以成立，但不能作为跨品牌、跨控制器、跨机床配置的统一操作规则。尤其是 G96 恒线速度会随着当前加工直径变化而改变主轴转速，靠近较小直径时可能显著升速；最高允许转速还受主轴、卡盘、夹紧方式、工件、刀具以及机床配置共同约束。

## 2. 原厂资料交叉核对

### Haas 车床语义（只代表该控制体系）

Haas 车床官方资料把 G96 / G97 列在 Group 13：

- G96：启用 Constant Surface Speed（恒定线速度）。主轴转速随当前切削直径和 S 指令值变化；英制/公制状态会影响 S 的线速度单位。
- G97：关闭 Constant Surface Speed；在该控制体系下，G97 生效时 S 表示 RPM。
- Haas 还明确建议在使用 G96 时设定最大主轴转速，并在该体系中使用 G50 作为主轴最高转速限制。

官方参考：

- https://www.haascnc.com/service/codes-settings.type%3Dgcode.machine%3Dlathe.value%3DG96.html
- https://www.haascnc.com/service/codes-settings.type%3Dgcode.machine%3Dlathe.value%3DG97.html
- https://www.haascnc.com/service/codes-settings.type%3Dgcode.machine%3Dlathe.value%3DG50.html
- https://www.haascnc.com/zh/service/online-operator-s-manuals/lathe-operator-s-manual/lathe---g-codes.html

### 为什么不能写成跨系统口诀

同一厂商的其它控制设备就可能使用完全不同的 G96 / G97 语义。例如 Haas Rotary Servo Control 手册中，G96 可表示子程序调用/跳转，G97 可表示延时。这足以说明“看到 G96/G97 就按车床恒线速/恒转速解释”不是可靠的跨设备规则。

参考：

- https://www.haascnc.com/service/online-operator-s-manuals/rotary-tailstock---operator-s-manual-supplement/rotary---g-codes.html

因此平台应把“先确认机床类型、当前 CNC、G 代码组别和原厂手册”放在所有 G96/G97 教学结论之前。

## 3. 零基础教学必须保留的安全边界

### G96

推荐面向新手的核心解释：

“在**部分明确支持该车床语义的 CNC** 中，G96 用于恒线速度控制。控制器会结合当前加工直径与 S 指令调整主轴转速。真实使用前必须确认当前 CNC 对 G96、S 单位和最高主轴转速限制方式的定义，并核对机床厂原厂手册。”

必须同时提醒：

1. 不能只背“G96 前写 G50”。G50 的具体含义、格式和适用范围必须以当前 CNC / 机床厂原厂手册为准。
2. 启用恒线速度后，直径减小时主轴转速可能上升；不能把某个教学 RPM 上限当成真实机床安全值。
3. 最高允许主轴转速必须同时受主轴、卡盘、夹爪/夹紧方式、工件、刀具和机床配置约束，取符合现场规范的安全限制。
4. 必须确认公制/英制或其它单位状态，以及 S 地址在当前控制器中的实际单位和含义。
5. 教学程序只用于理解语义；真实机床执行前必须核对原厂手册、现场工艺与安全制度，并按机床允许方式进行图形检查、仿真、单段、低倍率或其它受控验证。

### G97

推荐面向新手的核心解释：

“在**部分明确支持该车床语义的 CNC** 中，G97 用于取消恒线速度并进入固定主轴转速方式；该控制体系下 S 通常按主轴 RPM 解释。不能把这条语义跨控制器照抄。”

必须同时提醒：

1. 先确认当前 CNC 的 G96/G97 组别、模态关系、S 的解释和单位。
2. 切换前后都要确认主轴方向/状态、最高允许主轴转速以及卡盘、工件、刀具限制。
3. 禁止使用固定 `G97 S800 M03` 之类数值作为零基础用户可直接上机的范例。
4. 教学示例只能写成占位式语义，例如 `G97 S...`，并明确“数值和格式必须按本机原厂手册与现场工艺确定”。
