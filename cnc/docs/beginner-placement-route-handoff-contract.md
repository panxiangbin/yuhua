# CNC 起点测评到训练营的一次性路线交接契约

## 目标

起点测评完成后，零基础用户可以把“本次推荐路线与前三步”带到训练营查看，但该结果不得变成成绩、XP、通关、成长档案或错题记录。

## 数据边界

- 固定临时键：`cnc_beginner_placement_route_handoff_v1`。
- 只允许使用当前标签页的 `SessionStorage`。
- 只有用户点击“把本次路线带到训练营”时才写入。
- 数据只包含受控的路线分类、中文标题、受控站内入口和最多三步学习路线，不包含六道题答案。
- 有效期最多 5 分钟。
- 训练营必须先删除固定键，再解析、校验和显示。
- 刷新、浏览器返回或真实 BFCache 恢复不得再次显示已消费路线。
- 独立标签页不得读取另一个标签页的临时路线。
- `SessionStorage` 不可用时不得降级到 URL、LocalStorage、IndexedDB、成长档案或错题记录。
- 过期、损坏、来源不匹配、分类越界或站外链接必须拒绝并清理。

## 展示边界

训练营只显示：

1. 本次测评推荐起点；
2. 受控的前三步学习路线；
3. 第一步站内入口；
4. 已消费并清除、存储不可用或数据失效的中文恢复提示。

临时路线不得覆盖训练营依据正式学习记录生成的“系统推荐”。两者必须明确区分。

标题、路线说明和步骤名称即使来自同源页面，也必须按不可信文本处理：只能通过 `textContent`、`createTextNode` 等纯文本方式渲染，不得拼接到 `innerHTML`。包含尖括号、标签名称或属性文本的异常载荷只能原样显示，不能生成新的元素、脚本、图片、事件处理器或站外请求。

## 移动端与无障碍

- 真实视口为 390×844。
- 临时路线区域使用命名 `region`、礼貌播报和可程序聚焦标题。
- 可见操作目标不得小于 44×44 像素。
- 不得把路线分类、标题或步骤写入查询参数、URL 片段或站外请求。

## 安全与可信边界

起点测评只推荐学习路线，不代表岗位能力认证、现场上机许可或工艺放行。具体机床参数、报警、刀补、联锁和恢复操作必须核对相同版本原厂手册、企业制度、受控工艺与现场条件，并由授权人员确认。不得提供固定上机值、参数写入步骤、联锁绕过、盲目复位或未经验证的现场放行方法。

## 验收

独立 Chromium 门禁必须真实覆盖：

- 一次性写入和训练营立即消费；
- 刷新不恢复；
- 真实 `pageshow.persisted === true` 的 BFCache 返回不恢复；
- 过期与非法站外链接拒绝；
- 独立标签页隔离；
- `SecurityError` 存储异常恢复；
- SessionStorage-only、零长期写入、零 URL 泄露、零站外请求；
- 含 HTML 样式字符的标题、路线和步骤按纯文本显示，且不生成注入元素；
- 44px 触控目标和浏览器错误为 0。
