# CNC 12关主线课程目录三端防漂移契约

## 目的

手机闯关首页、训练营和 AI CNC 老师共同使用同一套12关主线课程：

- 手机闯关首页负责让零基础学员打开页面就知道下一步学什么；
- 训练营负责展示完整路线、成绩和训练建议；
- AI CNC 老师根据本机学习记录，用课程序号推荐真实的下一关入口。

如果其中任一端的课程顺序或正式目标单独变化，学员可能在首页看到第5关、在训练营进入另一门课，而 AI 老师又把“第5关”指向第三个页面。此类漂移会直接破坏学习路径和成长档案解释，因此必须由自动门禁阻止。

本门禁动态读取三端真实目录，不维护独立的第四份人工课程表。

## 必须保持一致的内容

手机闯关首页 `cnc/personal-home.js` 与训练营 `cnc/training-camp.html` 必须同时满足：

1. 均为12关；
2. ID严格按 `stage-1` 至 `stage-12` 排列；
3. 同一关的入口文件完全一致；
4. 同一关标题必须相同，或一端是在另一端基础上增加面向新手的解释性副标题；
5. 每关都必须保留明确的学习理由；
6. 12个入口解析后的正式课程目标不得重复。

AI CNC 老师 `cnc/ai-teacher.html` 还必须满足：

1. `COURSE_LINKS` 恰好包含12个不重复的站内课程入口；
2. 12个入口必须逐关解析到与手机闯关首页、训练营相同的正式课程目标；AI 老师可以直接使用正式页面，而手机首页和训练营可以为保护旧收藏继续使用受控兼容入口；
3. AI 老师自身使用兼容入口时，也必须通过同一套存在性、单层跳转、站内目标、手动继续按钮和安全边界检查；
4. “继续第 N 关”推荐必须通过 `COURSE_LINKS[state.nextCourse-1]` 取得入口，不得另写不受控分支；
5. 下一关计算和主线未完成判断必须明确覆盖固定12关。

不得通过改变解析规则、减少课程数、跳过某一关、把不同正式课程伪装成别名或另写隐藏入口来制造绿色结果。

## 课程入口与兼容入口

主线入口必须是仓库内的 `cnc/course-*.html` 页面，目标文件必须真实存在且是有效中文 HTML。

历史收藏、旧缓存或旧首页已经使用过的课程文件名，可以保留受控兼容入口，但必须满足：

- 兼容页自身可读取，不得是空文件；
- 只允许跳转到仓库内真实存在的正式课程页面；
- 不得跳转到站外、非课程页面、自身或另一层兼容入口；
- 必须提供可点击的手动继续按钮；
- 必须保留“教学参考、核对原厂手册和现场条件、由授权人员确认”的安全边界；
- 结构化报告必须记录兼容入口与正式目标的对应关系。

三端允许使用不同的受控入口文件，但逐关解析后的正式目标必须完全一致。兼容入口只能用于保护旧链接，不得掩盖正式课程缺失，也不得让 AI 老师绕开主线正式目标。

## Actions触发范围

工作流必须同时监听：

- `pull_request`；
- `main` 分支 `push`；
- `workflow_dispatch`。

`pull_request.paths` 与 `push.paths` 必须完全对称，并至少覆盖：

- `cnc/personal-home.js`；
- `cnc/training-camp.html`；
- `cnc/ai-teacher.html`；
- 所有 `cnc/course-*.html`；
- 本测试、本契约和工作流自身。

这样可以保证课程被删除、改名、换顺序、改入口、调整兼容跳转或修改 AI 老师下一关推荐时，门禁必然运行。

## 诊断与反绕过

成功或失败都必须上传结构化报告，至少包含：

- 三端源文件 SHA-256；
- 手机闯关首页和训练营的12关目录；
- AI CNC 老师的12个原始课程链接；
- 每关三端入口及解析后的正式目标；
- 受控兼容入口；
- PR 与 main push 路径过滤器；
- 具体失败原因。

工作流权限必须保持 `contents: read`，使用 Node 24，`cancel-in-progress` 必须为 `false`。不得使用 `test.skip`、`describe.skip`、`it.skip`、`process.exit(0)`，不得把 `cancelled`、`skipped`、排队或运行中状态当作成功。

## 教学与现场边界

12关课程和 AI CNC 老师的路线建议用于零基础学习和训练导航，不构成现场上机许可。课程中的程序、参数、转速、进给、切深、安全高度、刀补、报警、联锁、复位和恢复内容均为教学参考；实际使用必须核对相同系统和机型的原厂手册、企业制度、受控工艺与现场条件，并由授权人员确认。
