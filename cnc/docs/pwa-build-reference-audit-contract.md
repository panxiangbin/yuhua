# CNC PWA 构建引用审计契约

## 目的

防止 Service Worker、离线状态页、自检页、浏览器回归和部署工作流分别保留不同的 PWA 构建号，造成“页面显示已更新、实际缓存仍是旧版”或升级测试验证了错误版本。

## 必须满足

1. `cnc/build-info.json` 是当前 PWA 构建号的受控标记。
2. `cnc/sw.js`、`cnc/pwa-status.html`、`cnc/pwa-self-test.html` 以及核心 PWA 浏览器测试中的主动构建针必须与该标记一致。
3. 升级测试可以保留一个明确命名的上一版本构建号，用于验证旧 CNC 缓存被清理、学习数据和无关缓存不被删除。
4. 其他历史构建号不得散落在 CNC 页面、测试或工作流中；确需保留时必须以“上一版本”语义明确声明，并进入诊断报告。
5. 每次成功或失败都必须上传结构化报告，列出扫描文件、全部构建引用、主动构建针、上一版本引用和异常项。
6. 不得通过删除测试、降低断言、跳过步骤或将 `cancelled`、`skipped` 当作成功来通过门禁。

## 范围与安全边界

本门禁只审计 CNC PWA 构建与缓存可靠性，不修改成绩、XP、成长档案、题库记录或现场参数。离线课程只用于学习；具体机床参数、报警、刀补、联锁、复位和恢复操作必须核对相同版本原厂手册、企业制度、受控工艺和现场条件，并由授权人员确认。
