# G51 缩放运行时可信度审计

## 结论

当前 `cnc/gm-code-complete.js` 已收录 G51，但现有条目仍不足以直接作为零基础用户的高可信运行时说明。下一阶段应先建立独立门禁，再补 `normalizeG51` 第二层防御；在门禁完成前，不把任何品牌或控制器的 G51 格式包装成跨机床通用口诀。

## 当前发现

当前基础条目主要表达为：

- G51 用于按比例放大或缩小程序轨迹；
- 要确认缩放中心；
- 示例写有 `G51 X0 Y0 P2.0` “可能表示以原点为中心放大 2 倍”；
- 风险等级当前为“中”。

这些信息能帮助理解概念，但还缺少零基础用户实际需要的边界：

1. 没有明确要求先确认**当前 CNC、机床厂配置、G51 所属组别/模式和选项是否启用**。
2. 没有明确说明缩放可能持续影响后续运动段，因此不能只把它理解成“改图形大小”。
3. 没有要求核对缩放中心、缩放倍率、参与缩放的轴、圆弧参数、固定循环与补偿量等具体实现范围。
4. 没有明确禁止把某个品牌中的 `P` 范围、倍率表达方式或默认缩放中心当成通用规则。
5. 与刚进入 main 的 G50“取消缩放/其它多语义”可信度边界尚未形成成对的运行时保护。

## 原厂资料抽查

本审计只把原厂资料作为“存在控制器/机床实现差异”的证据，不据此推导所有 CNC 的统一行为。

Haas 当前铣床原厂 G51 文档将其定义为 Scaling（Group 11），并明确：

- 需要 Rotation and Scaling 选项；
- X/Y/Z 可用于指定缩放中心；
- P 为该控制器中的缩放因子；
- 若 G51 段没有指定缩放中心，该控制器会使用最后指令位置作为缩放中心；
- 缩放会影响后续快速、直线、圆弧位置，并涉及 I/J/K/R；
- 固定循环、刀补等项目存在单独的实现规则；
- Haas 铣床以 G50 取消 G51。

原厂来源：

- Haas Automation — G51 Scaling (Group 11): https://www.haascnc.com/service/codes-settings.type%3Dgcode.machine%3Dmill.value%3DG51.html
- Haas Automation — Mill G-Codes: https://www.haascnc.com/service/service-content/guide-procedures/mill---g-codes.html

**适用范围声明：**以上细节只证明 Haas 当前铣床存在这一实现，不能直接推广到 FANUC、三菱、西门子、广数、华中或其它控制器，也不能直接推广到车床、复合机或用户现场的特定机床。真实机床必须核对当前 CNC 与机床厂原厂手册。

## 建议的运行时安全边界

后续 `normalizeG51` 至少应做到：

- 风险等级提升为“高”或给出等价的高风险说明，因为它可能改变后续多个运动段的坐标解释；
- 明确 G51 的可用性、格式、倍率地址、倍率单位/表达方式、缩放中心和参与轴依当前 CNC 与机床厂配置而定；
- 明确要求执行前检查当前缩放状态、工件坐标、平面、刀补/刀长补偿、固定循环及后续全部运动空间；
- 提醒旋转轴、多轴、圆弧、固定循环和 CAM 后处理场景必须额外核对本机实现；
- 明确禁止提供“固定 P 值”“固定缩放中心”“固定轴地址”作为可直接上机照抄的通用写法；
- 与 G50 的取消缩放语义建立一致性检查，但同时保留 G50 在不同机型/控制器上的其它语义边界；
- 任何真实机床操作前都要求图形检查、仿真、单段/低倍率或现场规定的受控验证，并核对原厂手册。

## 下一阶段门禁

先新增独立 CNC-only 可信度 smoke，再改运行时。门禁至少应验证：

1. 基础源存在 G51 且说明适用范围，不把某品牌参数当通用标准；
2. 运行时必须存在并实际接入 `normalizeG51`；
3. G51 与 G50 的缩放启用/取消关系只在明确适用范围内表述；
4. 当前 CNC、机床厂原厂手册、选项/组别、缩放中心、倍率、参与轴和完整运动空间均为硬性安全提示；
5. 不允许 `.skip()`、吞错、固定成功退出或 `continue-on-error`；
6. 失败时上传真实诊断 Artifact；
7. 如果 `search-aliases.js` 因运行时整改变化，必须正规提升 PWA/cache revision，并重新跑 Service Worker、真实断源离线、PWA self-test、BFCache、手机首页、起点测评、完整 CNC 回归、性能、无障碍、Pages 与公网 exact-head。

## 范围

本审计及后续实现只允许修改 `cnc/**` 和明确只服务 CNC 的测试/工作流；不得修改予华仪器官网根目录、产品、图片或仪器数据。
