# AI CNC老师分类判断说明契约

## 目的

AI CNC老师已经能够区分高风险真实操作请求、安全原理讨论和普通学习问题。本契约要求用户能够看到“为什么被阻断”，但解释内容不得泄露可直接执行的参数值、参数写入步骤、安全联锁绕过方法或盲目复位方法。

## 页面职责

`cnc/ai-teacher-explainability.html` 是本地分类判断说明页。它通过同源隐藏页面读取正式 `window.CNC_AI_TEACHER.classifyQuestion`，不复制另一套独立分类器，也不调用外部模型或云端接口。

页面只显示：

- 最终分类：高风险阻断、安全原理说明或正常学习分流；
- 命中的受控风险类别；
- 命中的安全讨论语境；
- 是否存在强执行意图；
- 分类器提供的中文判断理由；
- 分类版本与解释页面版本。

## 四类高风险标签

| 受控标识 | 中文标签 | 说明边界 |
| --- | --- | --- |
| `exact-value` | 固定上机值 | 只说明请求涉及脱离具体条件的固定值，不提供任何数值 |
| `parameter-write` | 参数写入 | 只说明请求涉及参数修改或写入，不提供参数写入步骤 |
| `bypass-safety` | 安全绕过 | 只说明请求涉及联锁、安全门、限位、急停或保护绕过，不提供方法 |
| `blind-reset` | 盲目复位 | 只说明请求涉及原因未明时直接、连续或强制复位，不提供复位顺序 |

未知或新增的内部标识不得直接变成操作说明，只能显示为“受控类别”。

## 安全讨论与强执行意图

安全原理、风险、禁止原因或“明确不要操作步骤”的学习问题可以进入安全原理说明。但只要同时出现强执行意图，例如“顺便教我怎么关掉”“现场现在就要用”“照着做”，必须保持阻断。

判断说明页必须清楚显示：

- 安全讨论语境是否命中；
- 强执行意图是否命中；
- 强执行意图不能用“纯教学”“假设研究”等包装解除阻断。

## 同标签页一次性交接消费端

判断说明页提供受控的 SessionStorage 消费端，用于后续从 AI CNC老师页面传递“本次被阻断或进入安全原理说明的问题”。本轮只建立消费、校验、清理和自动解释能力，不在 URL 中传递问题，也不把问题写入长期学习记录。

固定键名：

```text
cnc_ai_teacher_explainability_handoff_v1
```

只接受以下 JSON 字段：

- `schemaVersion`：必须为 `1`；
- `source`：必须为 `ai-teacher`；
- `intent`：只允许 `blocked` 或 `safety-boundary`；
- `question`：去除首尾空白后必须为 1～120 个字符；
- `createdAt`、`expiresAt`：毫秒时间戳，有效期不得超过 5 分钟。

消费顺序必须是：

1. 从当前标签页的 SessionStorage 读取；
2. 立即删除固定键；
3. 再解析、校验和判断是否自动显示；
4. 合法时填入问题并调用正式分类器；
5. 非法、过期或来源不匹配时只显示已清理提示，不自动解释。

该顺序保证即使 JSON 解析、分类器加载或页面渲染失败，临时问题也不会继续残留。刷新页面不得再次自动显示已经消费的问题。

禁止：

- 把问题写入查询参数、URL 片段或页面标题；
- 把问题写入 LocalStorage、IndexedDB、课程档案、错题、模拟或考试记录；
- 接受普通学习问题作为自动交接，避免无必要扩大临时数据处理范围；
- 延长有效期超过 5 分钟；
- 在新标签页、其他浏览器或其他设备间同步临时问题。

## 数据与隐私

- 所有处理在浏览器本地完成；
- 仅加载同源 `cnc/ai-teacher.html`；
- 不访问外部模型、站外接口、WebSocket 或事件流；
- 不上传问题文本；
- 不保存问题文本到本地学习档案；
- 页面使用 `textContent` 渲染用户输入相关结果，禁止把输入拼接为 HTML。

## 内容可信度边界

判断说明页只证明问题被正确分流，不证明任何具体机床参数、报警、刀补、联锁或恢复步骤已经核实。

必须保留以下边界：

- 技术操作需核对相同版本原厂手册、企业制度、受控工艺和现场条件；
- 由现场师傅或授权人员确认；
- 资料清单与逐条复核记录不能互相代替；
- 未逐条复核内容不可直接上机。

## 可访问性与移动端

- 以 390×844 真实移动视口执行浏览器测试；
- 所有可见链接、按钮和输入框触控尺寸不得小于 44×44 像素；
- 判断结果使用 `aria-live="polite"`；
- 临时交接状态使用 `role="status"`；
- 隐藏分类引擎不得进入键盘焦点顺序；
- 页面不得出现横向滚动或浏览器错误。

## 门禁

独立门禁必须执行：

1. 页面和测试脚本语法检查；
2. 正式 AI老师移动端可信边界回归；
3. 34条高风险与正常学习分类样本回归；
4. 判断说明页四类标签、安全讨论、强执行意图和正常学习分流验证；
5. 合法临时问题自动消费、立即清除、无 URL 和长期存储写入；
6. 刷新后不得再次自动显示；
7. 过期或非法临时问题必须清除且不得自动解释；
8. 390×844 触控目标检查；
9. 零站外请求和零浏览器错误检查；
10. 成功或失败均上传截图、结构化结果、发现记录和服务器日志。

不得删除测试、降低断言、跳过步骤、使用 `process.exit(0)` 吞掉失败，或把 `cancelled`、`skipped`、排队和运行中状态当作成功。
