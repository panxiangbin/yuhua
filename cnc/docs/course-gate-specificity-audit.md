# 固定12关专属闯关题审计

## 审计目的

固定12关已经具备80分通关门槛，但闯关题必须真正对应本关学习目标，不能用同一道通用题跨越多个课程代替掌握证明。

本审计只检查 `cnc/training-practice.js`，不改变固定12关名称、顺序或课程文件。

## 当前基线

截至本审计建立时：

- 基础练习题共9道；
- 12关都配置了闯关映射；
- 只有第9关和第12关配置2道题，其余10关仅配置1道；
- `axis-z-direction`、`g01-feed`、`fill-g01`、`order-first-run`、`dry-run` 被跨关复用；
- 12关合计只有9道不同的门禁题。

这会导致“答对一题即100分”，并让不同课程共享同一掌握证据，不能充分证明新手已经理解本关内容。

## 稳定交付标准

1. 固定12关必须逐关配置不少于2道题；
2. 至少有24道互不重复的专属门禁题；
3. 门禁题不得跨关复用；
4. 每关题目必须覆盖本关核心主题；
5. 每题必须有中文解析和适用范围；
6. 高风险题必须明确原厂手册、企业制度、现场条件、授权或受控验证边界；
7. 不允许通过删除测试、放宽题目数量、降低80分门槛或伪造完成记录通过门禁。

## 适用范围与安全边界

题目只能讲通用学习原则。不同系统、机型、参数号、报警含义、刀补方式和现场步骤可能不同，必须核对机床原厂手册、企业安全制度、现场工艺和上机授权；涉及运动、装夹、对刀、试切和首件放行时，应先进行仿真、空运行、单段或低倍率等受控验证。
