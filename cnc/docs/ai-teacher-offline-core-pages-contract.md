# AI CNC老师离线核心 Pages 公网验收契约

## 目的

本门禁用于证明已经合并到 `main` 的 AI CNC老师离线核心资源确实进入 GitHub Pages 公网，而不是只存在于分支、提交记录或本地缓存中。

验证对象：

1. `cnc/sw.js`；
2. `cnc/build-info.json`；
3. `cnc/pwa-status.html`；
4. `cnc/pwa-self-test.html`。

## 精确部署要求

每个资源都必须分别读取远程 `main` 与 Pages 公网版本，并满足：

- HTTP 请求成功；
- 使用随机查询参数；
- 使用 `cache: no-store` 和禁止缓存请求头；
- 字节长度完全一致；
- SHA-256 完全一致；
- 当前分支、远程 `main` 与 Pages 公网完全一致；
- 最多进行 18 次真实部署等待，每次间隔 10 秒；
- 成功与失败均生成结构化诊断和 Artifact。

不得把页面“能打开”替代逐字节验证，也不得把旧版本仍可访问当成新版本已部署。

## 版本与核心缓存

验收版本固定为：

- 站点构建：`20260801-ai-handoff1`；
- PWA 构建：`20260802-pwa5`。

Service Worker 核心缓存必须按受控顺序包含 9 项资源，并同时包含：

- `./ai-teacher.html`；
- `./ai-teacher-intake.html`；
- `./ai-teacher-explainability.html`。

PWA 状态页和自检页必须使用相同构建号。自检页必须逐项核对 9 个资源，不能以重复条目、仅检查数组长度或修改显示数字伪造完整性。

## 可见安全边界

公网状态页与自检页必须继续说明：

- 离线内容可能不是最新版本；
- 报警、参数、刀补和现场操作仍须核对机床原厂手册、企业安全制度和现场条件；
- 高风险操作须由现场师傅或授权人员指导；
- 自检只读，不修改学习记录、不清空缓存、不发放 XP。

离线核心部署不代表任何具体参数、报警解释、刀补数值、联锁或恢复步骤已经完成原厂资料复核，也不允许提供固定上机值、参数写入顺序、安全绕过或盲目复位方法。

## 门禁防绕过

工作流必须：

- 使用 Node.js 24；
- 执行 JavaScript 语法检查；
- 禁止 `test.skip`、`describe.skip`、`it.skip`；
- 禁止用 `process.exit(0)` 吞掉失败；
- 禁止把重试次数设置为 0；
- 失败时保持非零退出码；
- 无论成功或失败都上传诊断 Artifact；
- 不把 queued、in_progress、cancelled 或 skipped 当作成功。

## 范围

本门禁只修改 CNC 专属测试、工作流和中文验收文档，不修改予华仪器官网根目录、产品、图片、仪器参数或产品数据，也不修改正式学习记录。
