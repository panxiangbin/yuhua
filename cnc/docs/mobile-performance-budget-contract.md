# CNC 手机端启动性能预算契约

## 目标

确保 CNC 新手训练平台在 390×844 手机环境中能够稳定、及时地进入五项闯关首页，并防止后续功能扩展造成资源体积、主线程阻塞、布局抖动或 DOM 规模失控。

本门禁是性能回归保护，不用于替代真实用户设备测试，也不宣称某一台机床、控制系统或网络环境的绝对体验。

## 覆盖范围

真实 Chromium 会在全新浏览器上下文中打开 CNC 首页，等待以下正式就绪条件：

- `CNC_TRUST_NAV` 已建立；
- `__CNC_TRUST_READY_AT__` 已记录；
- 五项手机主导航可见；
- 旧工具导航已隐藏；
- 页面完成稳定渲染。

随后记录并审计：

- DOMContentLoaded；
- 首次内容绘制 FCP；
- 最大内容绘制 LCP；
- 手机可信导航就绪时间；
- 请求数量与总传输体积；
- JavaScript、样式资源传输体积；
- 最长和累计主线程长任务；
- 累计布局偏移 CLS；
- DOM 节点数量；
- 加载层、五项导航、横向溢出和失败请求；
- 浏览器控制台及页面错误。

## 当前硬预算

| 项目 | 上限 |
|---|---:|
| DOMContentLoaded | 5000 ms |
| FCP | 5000 ms |
| LCP | 8000 ms |
| 手机可信导航就绪 | 10000 ms |
| 请求数量 | 160 |
| 总传输体积 | 12 MiB |
| JavaScript 传输体积 | 4 MiB |
| 样式资源传输体积 | 2 MiB |
| 最长长任务 | 1000 ms |
| 长任务累计 | 2500 ms |
| CLS | 0.25 |
| DOM 节点 | 6500 |

这些预算故意留有运行器波动余量，但不能因为功能增长随意上调。确需调整时，必须同时提供真实诊断、资源清单和原因说明，优先修复根因。

## 失败处理原则

门禁失败时必须读取完整作业日志以及以下 Artifact：

- `report.json`：完整指标、资源分类、最大资源和预算；
- `findings.txt`：全部阻断项；
- `mobile-home-390x844.png`：失败时页面真实状态。

禁止通过以下方式制造绿色结果：

- 删除指标或预算；
- 使用 `test.skip`、提前成功退出或跳过正式首页路径；
- 仅延长等待时间而不定位加载或主线程阻塞根因；
- 将失败请求、控制台错误、隐藏导航或加载层卡死当作成功；
- 把 `cancelled`、`skipped`、排队中或运行中的作业计为通过。

## 技术内容边界

本专项只验证网页性能和手机端可用性，不修改或背书机床参数、报警处置、刀补、坐标、加工程序和现场安全步骤。涉及具体机床的内容仍须标注适用范围，并要求核对原厂手册、现场工艺和空运行验证。
