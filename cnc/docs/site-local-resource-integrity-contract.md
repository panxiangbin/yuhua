# CNC 全站本地资源完整性契约

## 目标

CNC 新手训练平台由课程、测评、训练营、题库、现场模拟、成长档案、AI CNC 老师、PWA 状态页和大量静态资源组成。任意页面、脚本、样式或 PWA 清单引用不存在的站内文件，都会让零基础用户遇到空白页、404、图片缺失、按钮无响应或离线链路中断。

本门禁用于持续核验 `cnc/**` 生产资源之间的本地引用，不修改学习记录，不替代现有课程、手机浏览器、PWA、Pages 与内容可信度门禁。

## 扫描范围

自动扫描 CNC 生产目录中的：

- HTML 的 `href`、`src`、`action`、`poster`、`srcset` 和内联 CSS `url()`；
- CSS 的 `url()` 与 `@import`；
- 生产 JavaScript 中明确写出的同站 HTML、脚本、样式、JSON、清单、图片、视频、PDF 和文本资源；
- `manifest.webmanifest` 的启动页、图标、截图和快捷方式。

测试、文档、测试结果、Artifact、覆盖率目录和依赖目录不作为生产入口扫描源。

## 路径处理

门禁必须正确处理：

- `./`、`../` 相对路径；
- `/cnc/` 与 `/yuhua/cnc/` 公网路径；
- 查询参数与锚点；
- `srcset` 多候选资源；
- URL 编码和 HTML 实体；
- 指向 CNC 范围外的仓库资源只记录、不擅自修改或判定予华仪器官网内容；
- 网络地址、电话、邮件、Data URL、Blob URL 和纯锚点不作为本地文件检查对象。

`cnc/pwa-install-diagnostics.json` 是 Service Worker 在运行时写入 CacheStorage 的诊断响应，不是仓库静态文件，仅允许以明确白名单记录；不得借此扩大豁免范围。

## 有效性要求

每个受控本地目标必须：

1. 在大小写敏感的仓库路径中真实存在；
2. 不是空文件；
3. HTML 至少具有 `<html>`、标题和移动端 viewport；
4. JSON 与 Web App Manifest 可以被严格解析；
5. 目录目标必须存在 `index.html`；
6. 诊断报告必须列出扫描数量、引用数量、缺失项、无效项、运行时生成项、CNC 范围外引用和文件 SHA-256。

## Actions 契约

专用工作流必须：

- 同时监听 `pull_request`、`main push` 和手动运行；
- PR 与 `main` 使用相同的 `cnc/**` 触发范围；
- 使用 Node.js 24 和只读 `contents: read` 权限；
- `cancel-in-progress: false`，不得用取消旧运行掩盖失败；
- 先做 JavaScript 语法检查，再执行真实扫描；
- 成功或失败都上传结构化报告和可读诊断，缺少产物必须失败；
- 不允许 `continue-on-error`、测试跳过或成功退出伪装失败。

## 安全与内容边界

本门禁只确认站内资源链路完整，不证明课程中的程序、参数、转速、进给、刀补、报警、联锁、复位或恢复步骤可直接用于任何真实机床。

所有技术内容仍属于教学参考。具体使用必须核对相同系统和机型的原厂手册、企业安全制度、受控工艺、刀具与材料条件，并由现场师傅或授权人员确认。不得因为页面能打开、离线可用或门禁全绿，就把内容解释为现场上机放行结论。

## 禁止的通过方式

不得通过以下方式获得绿色门禁：

- 删除页面、课程、题库或模拟入口；
- 将缺失文件加入宽泛忽略清单；
- 忽略大小写、吞掉 JSON 解析错误或把空文件当成有效；
- 把 `cancelled`、`skipped`、`continue-on-error` 当作成功；
- 跳过扫描、降低断言、伪造报告或不上传失败诊断；
- 修改予华仪器官网根目录、产品、图片、参数或仪器数据来迁就 CNC 测试。
