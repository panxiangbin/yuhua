# AI CNC 老师判断说明一次性交接生产端契约

## 目标

当零基础用户在 AI CNC 老师页面提交问题，并被分类为“高风险阻断”或“安全原理说明”时，页面提供“查看本次判断说明”入口。入口只把本次问题临时交给同源判断说明页，用于解释命中的风险类别、判断理由和适用边界。

该能力不改变分类器结论，不提供固定上机值、参数写入步骤、联锁绕过方法、盲目复位方法或现场放行指令。

## 允许生成交接的分类

仅允许：

- `blocked`：高风险请求已阻断；
- `safety-boundary`：只讲安全原理、风险和核验流程。

普通课程问题、学习路线、G54 基础、刀补核对、报警基础、首件测量和快捷问题不得生成判断说明交接入口。

## 临时数据结构

固定键：

```text
cnc_ai_teacher_explainability_handoff_v1
```

结构：

```json
{
  "schemaVersion": 1,
  "source": "ai-teacher",
  "intent": "blocked 或 safety-boundary",
  "question": "长度 1～120 的原始问题",
  "createdAt": 0,
  "expiresAt": 0
}
```

约束：

- 只写入当前标签页 `SessionStorage`；
- 有效期不超过 5 分钟；
- 不写入 URL 查询参数或片段；
- 不写入 `LocalStorage`、IndexedDB、成长档案、错题或长期学习记录；
- 不上传，不调用外部模型或站外接口；
- 写入失败时不得显示“查看本次判断说明”入口；
- 普通学习问题和快捷问题必须清理遗留交接数据。

## 消费与返回

判断说明页必须沿用既有消费端契约：

1. 读取固定键；
2. 立即删除固定键；
3. 再解析、校验和显示；
4. 过期、损坏、来源不匹配或意图不允许时拒绝自动显示；
5. 刷新或返回后不得恢复已经消费的问题。

## 技术与安全边界

判断说明只解释风险类别与分流原因。涉及具体参数、报警、刀补、联锁、恢复操作和安全步骤时，必须核对相同版本原厂手册、企业制度、受控工艺和现场条件，并由授权人员确认。未逐条复核内容不可直接上机，资料清单与逐条复核记录不能互相代替。

## 自动门禁

移动端门禁必须在 390×844 真实 Chromium 环境中验证：

- 高风险阻断生成入口和 `blocked` 交接；
- 安全原理说明生成入口和 `safety-boundary` 交接；
- 判断说明页读取并立即清理；
- 问题不进入 URL、LocalStorage 或长期记录；
- 返回后已消费数据不会恢复；
- 普通学习问题和快捷问题不显示入口并清理旧数据；
- 可见触控目标不小于 44×44 像素；
- 站外请求和浏览器错误均为 0；
- 原有判断说明消费端回归继续执行，不得用生产端测试替代。
