# CNC新手起点测评无障碍 Pages 精确部署契约

## 目的

起点测评生产页面发生变更后，不能只凭本地测试、PR 绿灯、通用首页可访问或旧版 Pages 状态宣称新版已经上线。本门禁必须分别读取当前分支、远程 `main` 与 GitHub Pages 公网的 `cnc/beginner-placement.html`，确认正式版本真实部署。

## 精确一致性

- 请求必须添加随机查询参数，并使用 `Cache-Control: no-cache, no-store` 与 `cache: no-store`。
- 远程 `main` 与 Pages 必须 HTTP 成功。
- 必须比较完整文件字节数与 SHA-256；只有两者逐字节一致才算部署成功。
- 当前分支生产页面必须与远程 `main` 一致，避免用未合并分支或旧页面冒充正式验收。
- 允许最多 18 次真实部署等待，每次保留时间、HTTP、字节、SHA-256、缓存头和最后修改时间。
- 超时、HTTP 失败、内容契约缺失、字节不同或 SHA-256 不同均必须失败。

## 公网无障碍契约

公网页面必须真实包含并保持：

- `progressbar`、最小值0、最大值6、当前值与中文进度说明；
- 由题目标题命名的 `radiogroup`；
- 每个选项的 `radio`、`aria-checked` 与单一 Tab 停靠点；
- 方向键循环切换及 Home、End 操作；
- 未选择提示的 `role=status`、礼貌播报与程序化焦点；
- 换题后题目标题焦点；
- 结果命名区域、推荐理由与路线关联、完成后结果标题焦点；
- 重新测评后第一题焦点；
- 至少3px可见焦点轮廓；
- `prefers-reduced-motion: reduce` 下关闭进度过渡动画。

## 隐私和网络

- 答案与结果只保留在页面内存。
- 不得写入 LocalStorage、SessionStorage、IndexedDB、成长档案、错题记录或 URL。
- 不得调用外部模型、站外接口、WebSocket 或 EventSource。
- 不得为了通过部署门禁删除真实交互断言、降低可访问性要求或跳过失败。

## CNC可信边界

起点测评仅推荐学习路线，不是现场放行结论。安全基础必须优先于操作熟练度。

涉及具体参数、报警、刀补、联锁和恢复操作，必须核对相同版本原厂手册、企业制度、受控工艺与现场条件，并由授权人员确认。页面和门禁不得给出固定上机值、参数写入步骤、联锁绕过、盲目复位或未经验证的操作结论。

## 诊断产物

成功和失败都必须上传结构化 `report.json` 与 `findings.txt`。诊断至少记录每次部署检查、最终字节数、SHA-256、公网响应信息、无障碍契约和安全边界结果，保留14天。
