# CNC 起点测评路线目录防漂移契约

## 目的

起点测评页面负责产生推荐路线，训练营负责读取并验证该路线。两端都保存了决策分类、标题、路线说明、第一步入口和步骤清单。任何一端单独修改而另一端未同步，都可能导致合法测评结果被拒绝，或让安全基础未通过的学习者进入错误路线。

本契约通过自动门禁交叉读取两个正式页面，阻止生产端和消费端静默漂移。

## 受控页面

- 生产端：`cnc/beginner-placement.html`
- 消费端：`cnc/training-camp.html`

## 必须完全一致的字段

每个决策分类必须逐字段一致：

- `decision`
- `title`
- `route`
- `href`
- `steps[].title`
- `steps[].href`

交接键和有效期也必须一致：

- 固定键：`cnc_beginner_placement_route_handoff_v1`
- 最长有效期：5 分钟

## 固定决策集合

只允许以下四类：

1. `critical-safety`：关键安全项存在危险答案，必须回到安全基础。
2. `low-score`：总分较低，按完整安全基础路线开始。
3. `foundation-gap`：关键安全项未出现危险答案，但坐标、对刀、刀补或安全确认仍需补强。
4. `advanced-ready`：关键安全项和基础题达到受控条件，可进入程序验证与首件检查学习。

`critical-safety` 与 `low-score` 可以共用同一条安全基础路线；除此之外不得新增未声明的重复路线别名。

## 链接与内容边界

- 所有入口必须是 `./名称.html` 形式的 CNC 站内相对链接。
- 每个目标文件必须真实存在于 `cnc/`。
- 标题、路线说明和步骤名称不得包含 HTML 尖括号。
- 训练营必须继续从受控目录返回标题、路线和步骤，不得直接信任临时载荷中的显示文字。
- 交接仍只允许使用当前标签页的 SessionStorage；不得降级写入 URL、LocalStorage、IndexedDB、成绩、XP、成长档案或错题记录。

## 失败处理

出现以下任一情况必须失败，不得跳过或降级断言：

- 两端决策集合不同；
- 任一字段不一致；
- 交接键或有效期不一致；
- 出现未声明的重复路线；
- 出现站外链接、非 HTML 入口或不存在的目标文件；
- 消费端不再按受控目录进行分类与路线完整性校验。

门禁必须生成结构化诊断报告，记录两端文件 SHA-256、决策目录、链接集合和具体失败原因。

## 教学与现场边界

起点测评只用于推荐学习路径，不代表岗位能力认证、现场上机许可或工艺放行。具体机床参数、报警、刀补、联锁、复位和恢复操作，必须核对相同版本原厂手册、企业安全制度、受控工艺和现场条件，并由授权人员确认。
