# CNC 资源修复 Pages 精确传播契约

## 目的

全站本地资源完整性门禁已经修复两项真实生产缺口：

1. 旧课程使用的 `training-profile.html` 成长档案兼容入口；
2. 知识卡片图片加载失败时使用的教学图片回退 SVG。

仓库中的文件存在，不等于 GitHub Pages 公网已经完成传播。本契约要求对这两项资源执行 main 与 Pages 公网的逐字节、SHA-256 和语义一致性验收，防止“代码已合并但公网仍是 404、旧文件或错误缓存”。

## 成长档案兼容入口

`cnc/training-profile.html` 必须：

- 只跳转到同站 `profile.html`，不得跳往站外；
- 保留查询参数和锚点，避免旧收藏或课程链接丢失上下文；
- 不读写 LocalStorage、SessionStorage、IndexedDB 或其他学习数据；
- 提供不小于 48px 的手动继续入口；
- 明确说明兼容页不会修改学习记录；
- 使用 `noindex`，避免历史入口被搜索引擎当成独立课程页。

## 教学图片回退

`cnc/assets/images/batch01_core/placeholder.svg` 必须：

- 保留固定 `viewBox`，避免手机端布局跳动；
- 具有可访问名称和可访问描述；
- 不包含脚本、`foreignObject`、JavaScript URL 或其他主动内容；
- 明确显示“教学图片正在补充”；
- 明确要求以课程文字、原厂手册和现场条件为准；
- 不能把回退图当作已核实的真实机床结构、刀路或安全操作示意。

## Pages 验收

门禁必须同时读取：

- 当前分支中的本地资源；
- `main` 分支的原始资源；
- GitHub Pages 公网资源。

只有以下条件全部满足，才允许通过：

- 两项资源在当前分支均存在且非空；
- 本地资源满足对应语义契约；
- main 与 Pages 公网资源字节数完全一致；
- main 与 Pages 公网资源 SHA-256 完全一致；
- main 与 Pages 公网资源均满足对应语义契约；
- 失败时仍生成结构化诊断和可读错误文件；
- 不得使用跳过测试、吞掉错误、零次重试、把 404 当成功或降低语义断言的方式放行。

## 技术与安全边界

本门禁只确认资源存在、可访问、逐字节一致且语义边界未漂移，不代表任何课程程序、参数、刀补、报警、联锁或恢复步骤可以直接用于真实机床。

所有机床相关内容均为教学参考；实际使用必须核对相同系统和机型的原厂手册、企业制度、受控工艺和现场条件，并由授权人员确认。不得修改予华仪器官网根目录、产品、图片、参数或仪器数据。
