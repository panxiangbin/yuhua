# CNC 正式课程可见开发占位审计契约

## 目的

CNC 新手训练平台已经具备 12 关主线课程、题库、模拟训练、成长档案和 PWA 能力。正式课程页不应继续向学员显示“图片 / 动画位”“建议后续加入”等面向开发阶段的占位文案，否则会让零基础学员误以为课程未完成，并降低内容可信度。

本门禁用于扫描 `cnc/course-*.html` 的可见正文，识别开发阶段占位，不检查脚本、样式和 HTML 注释中的维护说明。

## 必须识别的占位类型

- “图片 / 动画位”一类开发占位标题；
- “建议后续加入”“建议后续补充”一类内部施工说明；
- “图片待补充”“动画需制作”“内容待完善”一类未完成提示；
- `TODO`、`FIXME`、`TBD`、`COMING SOON`、页面开发中或建设中等开发标记。

## 允许的内容边界

以下内容不能因为措辞相近而被误删或放宽：

- 用于教学的程序空白，例如要求学员根据材料、刀具和现场条件填写转速、进给或安全高度；
- 明确说明参数不固定、必须核对原厂手册的教学提示；
- 图片加载失败时的受控无障碍回退资源；
- 测试、文档、工具和注释中的维护说明。

## 诊断与门禁要求

门禁必须：

1. 动态扫描仓库当前全部 `cnc/course-*.html`，不得另建容易漂移的人工课程名单；
2. 至少确认扫描到 12 个课程或兼容课程页面；
3. 对每个发现记录文件、行号、规则、命中文本和可读上下文；
4. 成功或失败都生成结构化 JSON；
5. 失败时额外生成可读错误文件并上传 Artifact；
6. 不得使用 `test.skip`、`continue-on-error: true`、零次执行、吞掉退出码或把 Artifact 上传成功当作课程审计成功；
7. 在 `pull_request` 与 `main push` 使用同一套路径和断言。

发现占位时，正确处理方式是读取真实诊断，逐页将占位替换为可交付的教学内容，或在确认误报后精确修正规则。不得通过删除规则、加入宽泛忽略、降低断言或把占位搬进不可见区域来放行。

## 技术与安全边界

本门禁只确认课程交付文案中没有开发阶段占位，不代表任何程序、参数、刀补、报警、联锁、回零或故障恢复步骤可直接用于真实机床。

所有机床相关内容均为教学参考；实际使用必须核对相同系统和机型的原厂手册、企业安全制度、受控工艺和现场条件，并由授权人员确认。只允许修改 `cnc/**`、明确只服务 CNC 的测试、工作流、文档和测试数据；不得修改予华仪器官网根目录、产品、图片、参数或仪器数据。
