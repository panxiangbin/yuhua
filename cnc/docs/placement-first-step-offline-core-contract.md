# 起点测评推荐首步课程冷离线契约

## 目标

用户首次联网打开 CNC 平台并完成 PWA 安装后，即使随后断网，也应能完成起点测评、进入训练营，并打开推荐路线的第一步课程。该能力只保障学习路径连续，不代表现场上机许可。

## 受控首步课程

起点测评当前四类结果实际对应三种不同的第一步课程：

- `critical-safety`、`low-score`：`course-safety-foundation.html`；
- `foundation-gap`：`course-coordinate-axes.html`；
- `advanced-ready`：`course-g00-g01-basics.html`。

上述三个页面必须同时存在于：

1. Service Worker 的 `REQUIRED_CORE_PATHS`；
2. PWA 离线浏览器回归的核心资源清单；
3. PWA 自检页的受控资源清单；
4. PWA 升级数据保护回归的冷离线验证；
5. 起点测评与训练营路线目录及目标页面触发门禁。

## 首次安装冷离线验收

在新的 390×844 Chromium 用户目录中完成一次联网安装后，必须切换为离线并真实验证：

- 起点测评可以打开并完成关键安全项硬门禁判断；
- 一次性路线可带入训练营，并在读取后立即从 SessionStorage 清除；
- “开始第1步”按钮真实跳转到安全基础课程；
- 安全基础、坐标轴与回零、G00/G01 基础三张课程页均可在从未访问过的情况下离线打开；
- 页面标题、中文学习内容、原厂手册和授权人员边界仍然存在；
- 可见链接和按钮触控区不得小于 44×44 像素；
- 不得写入或改变成绩、XP、成长档案、错题记录和模拟训练记录。

## 升级与版本

本能力使用 `20260803-pwa9`，上一正式缓存版本为 `20260802-pwa8`。升级回归必须确认：

- 旧 CNC 静态缓存和运行时缓存被清理；
- 新的两类缓存建立完成；
- 与 CNC 无关的缓存不被删除；
- LocalStorage、SessionStorage 和 IndexedDB 学习数据保持不变；
- 三张首步课程在升级后仍可冷离线打开；
- Service Worker、构建标记、状态页、自检页、浏览器回归和 Pages 门禁构建号一致。

## 内容可信与现场安全边界

课程中的程序、转速、进给、切深、安全高度、刀补、报警、联锁、复位和恢复步骤均只能作为教学参考。具体使用必须核对相同系统和机型的原厂手册、企业制度、受控工艺、刀具材料与现场条件，并由授权人员确认；不得将测评推荐或离线可用状态解释为上机放行结论。

## 禁止的通过方式

不得通过删除课程、减少首步路线、降低断言、跳过浏览器离线步骤、忽略构建漂移、将 `cancelled` 或 `skipped` 计为成功、伪造诊断文件或清空学习数据来获得绿色门禁。成功或失败均应保留真实日志和结构化 Artifact。
