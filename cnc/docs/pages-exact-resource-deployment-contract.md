# CNC Pages 具体资源部署契约

## 目的

GitHub Pages 的构建标识一致，并不等于每一个关键 JavaScript 文件都已经刷新。该门禁直接比较 `main` 与 Pages 公网资源的字节长度和 SHA-256，防止边缘缓存、部署延迟或错误发布让旧脚本继续服务。

## 当前关键资源

1. `cnc/mobile-trust-nav.js`
   - 必须保留手机五项主导航就绪契约。
   - 必须保留无障碍基础层和有限次数同步机制。
   - 禁止重新引入全局 `MutationObserver` 微任务循环。

2. `cnc/ui-knowledge-tree.js`
   - 必须保留知识树按需物化机制。
   - 首屏只允许生成根节点及直接子级。
   - 更深层节点只能在用户展开父节点时创建。
   - 每个子级容器只允许物化一次。
   - 禁止恢复完整知识树的首屏递归渲染。

## 验证规则

- 请求必须带随机查询参数，并使用 `no-store`、`no-cache` 请求头。
- `main` 原始资源与 Pages 公网资源必须同时返回成功状态。
- 两端字节长度必须完全相同。
- 两端 SHA-256 必须完全相同。
- 本地分支、`main` 与 Pages 公网文件都必须通过对应资源契约检查。
- 每个资源生成独立 JSON 诊断结果，不能被后一项覆盖。
- 任一资源未部署、内容不一致或契约缺失，整个 Pages 门禁必须失败。

## 禁止的通过方式

不得通过以下方式制造绿色结果：

- 删除具体资源验证步骤。
- 提高重试次数来掩盖长期部署故障。
- 只比较文件名、HTTP 状态或构建标识。
- 跳过 SHA-256 或字节长度检查。
- 放宽知识树按需渲染断言。
- 把 `cancelled`、`skipped`、排队中或未生成作业视为成功。

## 范围边界

本契约只服务 CNC 新手训练平台。不得借此修改予华仪器官网根目录、产品、图片、仪器参数或仪器数据，也不涉及机床参数、报警、刀补、坐标和现场安全结论。
