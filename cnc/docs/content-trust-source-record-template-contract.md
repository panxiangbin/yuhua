# CNC 内容复核来源记录模板契约

## 目标

为报警、G/M 代码、现场诊断、补充知识和课程内容建立统一的可追溯来源记录格式。模板解决“资料拿到了以后怎样登记”的问题，不负责伪造手册、替代专业复核或自动批准上机操作。

## 统一边界

所有来源记录继续保持：

> 教学参考，需按机床说明书、现场工艺和空运行验证

结构校验通过只表示字段完整、格式可追溯，不表示技术结论正确，不表示适用于所有系统或机床，也不表示可以直接修改参数、写入刀补、执行报警恢复或运行程序。

## 文件

- `cnc/content-trust-source-record.schema.json`：来源记录 JSON Schema；
- `cnc/content-trust-source-record-template.json`：不预填任何来源的空白模板；
- `cnc/tools/validate-content-trust-source-record.cjs`：本地校验工具；
- `cnc/tests/content-trust-source-record-template-smoke.cjs`：结构、防占位和防伪造回归测试。

## 必填内容

每条实际来源记录必须包含：

- 数据集路径和可稳定定位的条目键；
- 来源类型；
- 发布机构；
- 文档名称；
- 文档编号或版本；
- 适用系统、控制器或机床；
- 页码或章节；
- 受控资料位置或可追溯链接；
- 复核日期和复核人；
- 复核说明；
- 适用范围说明；
- 复核结论；
- `onMachineValidationRequired: true`。

资料文件可用时可以补充 64 位小写 SHA-256。不得把受版权保护的完整原厂手册直接提交到仓库；应登记受控位置、文档编号、版本和必要章节。

## 允许的来源类型

- `oem_manual`：数控系统、刀具或设备原厂正式手册；
- `machine_builder_manual`：机床制造商的操作、报警、M 代码或 PLC 资料；
- `official_standard`：正式发布且适用范围明确的标准；
- `supplier_technical_data`：刀具、材料或测量设备供应商正式技术数据；
- `controlled_site_record`：受控工艺卡、检验记录、安全制度或培训文件。

论坛帖子、无版本截图、无法追溯的短视频、搜索摘要和模型生成内容不能作为完成技术复核的唯一证据。

## 复核结论

- `supported_for_stated_scope`：来源支持当前明确写出的适用范围；
- `conflicts_with_source`：现有内容与来源冲突，需要修正；
- `insufficient_evidence`：资料不足，继续保持待复核；
- `not_applicable`：该来源不适用于当前系统、机床或条目。

结论必须和适用范围、章节及说明一起登记，不能只写“正确”或“错误”。

## 使用方式

复制空白模板后填写实际来源记录，再执行：

```bash
node cnc/tools/validate-content-trust-source-record.cjs <来源记录.json>
```

校验工具会拦截：

- 缺少必填字段；
- 未允许的数据集、来源类型或结论；
- “待填写、未知、TODO、示例”等占位内容；
- 无效日期或 SHA-256；
- 关闭现场验证要求；
- 未受控额外字段；
- 同一条目、文档版本和章节的重复记录。

## 禁止事项

不得通过以下方式制造“已核实”状态：

- 猜测手册名称、版本、章节或适用系统；
- 用测试记录、占位内容或模型回答冒充真实证据；
- 只记录链接而不记录发布机构、版本和章节；
- 把字段完整等同于技术结论已核实；
- 把资料来源登记等同于允许直接上机；
- 删除测试、降低断言、跳过步骤或把 `cancelled`、`skipped` 当作成功；
- 修改予华仪器官网根目录、产品、图片或仪器数据。
