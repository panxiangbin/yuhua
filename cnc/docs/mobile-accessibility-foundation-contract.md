# CNC 手机端无障碍基础审计契约

## 目标

让 CNC 新手训练平台在 390×844 手机环境、键盘操作、屏幕阅读器基础语义和“减少动态效果”设置下，仍能完成核心导航与学习入口操作。

本契约只约束网页可访问性，不修改课程结论、机床参数、报警处理、刀补、坐标、安全高度或现场工艺。

## 必须持续验证

1. 文档语言为 `zh-CN`，页面只有一个可见主内容地标。
2. 页面提供可键盘聚焦的“跳到主内容”入口，目标为稳定的主内容 `id`。
3. 所有可见按钮、链接和表单控件具备可访问名称。
4. 输入框、选择框和文本域不得只依赖占位文字作为说明。
5. 禁止正数 `tabindex`，禁止在 `aria-hidden="true"` 区域保留可聚焦控件。
6. 390px 宽度下不得出现横向溢出。
7. 手机目录按钮必须提供 `aria-controls` 和实时 `aria-expanded` 状态。
8. 目录打开后焦点进入目录；按 `Escape` 关闭后焦点返回原按钮。
9. 邀请码、复制和表单错误提示必须通过 `aria-live` 或状态角色播报。
10. 用户启用“减少动态效果”时，非必要动画和过渡必须关闭。
11. 键盘焦点必须清晰可见。
12. 控制台和页面不得出现 JavaScript 错误。

## 诊断产物

无论门禁成功或失败，都上传：

- 390×844 完整页面截图；
- `report.json` 结构化审计结果；
- `findings.txt` 中文阻断项清单。

## 修复原则

- 修复真实语义、焦点管理和动态效果问题，不通过删除检查、降低断言或跳过路径制造绿色结果。
- 保持手机首页五项主导航、Service Worker、PWA、BFCache、学习数据和既有完整 CNC 回归不受影响。
- 技术内容继续面向零基础；涉及机床系统、参数、报警、刀补、坐标和安全步骤时，必须注明适用范围，并要求核对原厂手册、受控工艺和现场条件。
