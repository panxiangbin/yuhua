# CNC 内容复核证据资源 Pages 部署契约

## 目标

内容复核证据台账和资料准备度页面合并到 `main` 后，必须确认 GitHub Pages 公网实际部署了同一份文件，不能只凭提交记录、构建号或仓库文件存在就宣称已经上线。

## 精确核验资源

- `cnc/content-trust-evidence.html`
- `cnc/content-trust-evidence-ledger.json`

门禁分别从 `main` 原始文件和 Pages 公网读取资源，使用随机查询参数、`no-store` 和禁止缓存请求头；两侧字节数与 SHA-256 必须完全一致。

## 页面契约

公网资料准备度页面必须保留：

- `zh-CN` 页面语言；
- “CNC 内容复核资料准备度”标题；
- 对证据台账的 `no-store` 请求；
- 统一提示“教学参考，需按机床说明书、现场工艺和空运行验证”；
- 资料已齐数量、来源记录数量、阻断原因和资料请求清单；
- 返回内容可信度状态和 CNC 新手训练平台的入口。

## 台账契约

公网证据台账必须保持：

- `schemaVersion` 为 1；
- 5 个高风险数据集完整登记；
- 报警数据和 G/M 代码数据为 P0；
- 8 个来源必填字段完整；
- 当前 5 项均为 `awaiting_sources`；
- `readyForItemReview` 为 0 项；
- 来源记录为 0 条；
- 已逐条复核为 0 条；
- 每项均有至少两条资料请求和明确阻断原因。

这些“0”是当前真实证据状态，不是质量成绩。取得并登记可追溯资料后，应通过新的审计变更更新，不能为了维持固定数字阻止真实进展。

## 重试与诊断

Pages 部署可能晚于 `main` 更新。门禁最多进行 18 次真实公网重试，每次间隔 10 秒；失败时必须保留每次 HTTP、字节数、SHA-256 和错误信息。成功或失败都写入 Pages 诊断 Artifact。

## 禁止事项

不得通过以下方式制造绿色结果：

- 只检查 HTTP 200，不比较字节和 SHA-256；
- 删除页面或台账契约；
- 把缓存中的旧文件当作最新部署；
- 把“资料准备度页面已部署”解释为报警、G/M 代码或诊断内容已经核实；
- 删除测试、降低断言、跳过步骤或把 `cancelled`、`skipped` 当作成功；
- 修改予华仪器官网根目录、产品、图片或仪器数据。
