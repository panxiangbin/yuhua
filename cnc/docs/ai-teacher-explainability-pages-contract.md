# AI CNC老师判断说明页 Pages 公网验收契约

## 目标

对 `cnc/ai-teacher-explainability.html` 建立独立、可重复的公网部署门禁，避免仅凭仓库文件或通用 Pages 首页检查就宣称判断说明页已经上线。

## 必须验证的资源关系

门禁分别读取：

1. 当前分支中的判断说明页；
2. 远程 `main` 中的同一资源；
3. GitHub Pages 公网中的同一资源。

远程请求必须使用随机查询参数、`cache: no-store`、`Cache-Control: no-cache, no-store` 和 `Pragma: no-cache`。Pages 与 `main` 必须同时满足字节数一致和 SHA-256 一致。

## 必须保持的语义

公网页面必须保留：

- 判断说明版本 `20260802-v1`；
- 正式分类版本 `20260802-v2`；
- 固定上机值、参数写入、安全绕过、盲目复位四类风险标签；
- 强执行意图优先规则；
- 通过同源 `ai-teacher.html` 复用正式分类器，不复制第二套判断逻辑；
- 本地运行，不调用外部模型或站外接口；
- 可见文本“本页不提供固定上机值”；
- 可见文本“不把用户问题转换成可直接上机的操作步骤”；
- 具体参数、报警、刀补、联锁和恢复操作必须核对相同版本原厂手册、企业制度、受控工艺和现场条件；
- 资料清单与逐条复核记录不能互相代替；
- 未逐条复核内容不可直接上机。

可见边界必须出现在页面 `body` 中，不能只存在于 meta 描述、测试代码或注释中。

## 禁止绕过

门禁不得：

- 删除或跳过失败断言；
- 使用 `test.skip`、`describe.skip` 或 `it.skip`；
- 把重试次数设置为 0；
- 将 HTTP 失败、字节不一致或 SHA-256 不一致视为成功；
- 用当前分支文件代替远程 `main` 或 Pages 公网响应；
- 把资料清单登记冒充逐条技术复核；
- 加入固定上机值、参数写入顺序、联锁绕过或盲目复位步骤。

## 状态解释

- 当前分支与 `main` 不一致时，可以标记为“分支待合并”，但不能把分支内容宣称为已部署。
- `main` 与 Pages 不一致时必须失败并等待真实部署，不能降级为警告。
- 只有公网可达、字节和 SHA-256 精确一致、语义契约通过时，才允许报告判断说明页已经上线。

## 诊断产物

成功和失败都必须上传：

- `report.json`：请求次数、HTTP 状态、字节、SHA-256、缓存响应头、版本与语义结果；
- `findings.txt`：中文验收摘要或真实错误堆栈。

本契约只服务 CNC 新手训练平台，不涉及予华仪器官网、产品、图片、参数或仪器数据。
