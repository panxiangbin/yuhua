使用文档 / API 说明

系统采用数据驱动架构，核心类为 LearningPathSystem。你可以替换 demoData，接后端接口、LocalStorage 或本地知识库。

初始化

const app = new LearningPathSystem({
  root: "#learningPathApp",
  data: demoData
});

app.init();

核心 API

app.renderSkillTree(skillTreeData);
app.updateNodeStatus("g54", "done");

app.updateStats({
  totalNodes: 24,
  completedNodes: 12,
  learningMinutes: 860,
  streakDays: 7
});

app.renderChart(chartData);
app.unlockBadge("starter");
app.checkIn("2026-07-02", 45);
app.renderHeatmap(checkins);

app.renderGraph(nodes, edges);

技能树数据格式

{
  nodes: [
    {
      id: "g54",
      label: "G54坐标系",
      x: 120,
      y: 160,
      status: "current",
      category: "基础",
      desc: "掌握工件坐标系设定。"
    }
  ],
  edges: [
    { from: "base", to: "g54" }
  ]
}
