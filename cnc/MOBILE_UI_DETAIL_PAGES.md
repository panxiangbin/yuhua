### 1.2 搜索状态切换

搜索页面有三种状态，根据用户输入阶段切换：

```
初始状态 (未输入):
  - 区域 A: 显示历史搜索标签
  - 区域 B: 显示热门搜索/推荐搜索词

输入状态 (输入中, >2字后):
  - 区域 A: 隐藏历史搜索
  - 区域 B: 显示联想建议列表 (异步加载)
  - 联想建议匹配知识库标签和标题

结果状态 (提交搜索/选择建议):
  - 区域 A: 隐藏
  - 区域 B: 显示搜索结果列表
  - 结果按相关度排序
  - 可选按类型/分类筛选
```

### 1.3 搜索交互规范

```javascript
// 搜索逻辑
var searchTimer = null;
var MIN_SEARCH_LENGTH = 2;
var SUGGESTION_DELAY = 150; // ms

function onSearchInput(value) {
  clearTimeout(searchTimer);
  if (value.length < MIN_SEARCH_LENGTH) {
    showHistorySearch(); // 显示历史搜索
    return;
  }
  searchTimer = setTimeout(function() {
    fetchSuggestions(value);
  }, SUGGESTION_DELAY);
}

function fetchSuggestions(keyword) {
  // 从知识库标签中匹配前10个
  var matches = knowledgeBase.tags.filter(function(tag) {
    return tag.indexOf(keyword) !== -1;
  }).slice(0, 10);
  renderSuggestions(matches);
}
```

### 1.4 搜索结果排序规则

```
1. 标题完全匹配: 最高优先级
2. 标题部分匹配: 按匹配度降序
3. 标签匹配: 按标签数量降序
4. 全文匹配: 按关键词密度降序
5. 深度文件优先: 同匹配度下大文件优先

每页显示: 20 条
加载更多: 底部自动触发
```

### 1.5 搜索结果筛选

搜索结果支持按类型快速筛选（搜索结果上方的标签栏）：

```
[ 全部(47) | G代码(12) | M代码(8) | 刀具(6) | 材料(5) | 案例(4) | ... ]
```

- 标签栏可横向滑动
- 选中标签更新结果列表
- 标签计数随当前搜索结果实时更新

### 2.3 表格适配

由于手机屏幕窄，大表格需转换为卡片列表：

```javascript
function responsiveTable(table) {
  if (window.innerWidth < 600) {
    // 转换为卡片列表
    var rows = table.querySelectorAll('tr');
    var cardHtml = '<div class="table-cards">';
    rows.forEach(function(row, idx) {
      if (idx === 0) return; // 跳过表头
      var cells = row.querySelectorAll('td, th');
      cardHtml += '<div class="table-card">';
      for (var i = 0; i < cells.length; i++) {
        cardHtml += '<div class="card-field">' +
          '<span class="field-label">' + (tableHeaders[i] || '') + '</span>' +
          '<span class="field-value">' + cells[i].textContent + '</span>' +
        '</div>';
      }
      cardHtml += '</div>';
    });
    cardHtml += '</div>';
    table.insertAdjacentHTML('afterend', cardHtml);
    table.style.display = 'none';
  }
}
```

```javascript
var FONT_SIZES = [16, 18, 20, 22, 24];
var currentSizeIndex = 1; // 默认 18px

function adjustFontSize(delta) {
  currentSizeIndex = Math.max(0, Math.min(FONT_SIZES.length - 1, 
    currentSizeIndex + delta));
  var size = FONT_SIZES[currentSizeIndex];
  document.querySelector('.detail-content').style.fontSize = size + 'px';
  localStorage.setItem('cnc_font_size', size);
```

**练习题交互规范**：

```javascript
var quizState = {
  current: 0,
  total: 5,
  answers: [],
  correct: 0,
  startTime: Date.now()
};

function selectAnswer(questionIndex, optionIndex) {
  var isCorrect = questions[questionIndex].answer === optionIndex;
  quizState.answers[questionIndex] = optionIndex;
  if (isCorrect) quizState.correct++;
  
  // 显示结果
  showResult(isCorrect, questions[questionIndex].explanation);
  
  // 自动进入下一题 (2s后)
  if (quizState.current < quizState.total - 1) {
    setTimeout(function() { nextQuestion(); }, 2000);
  } else {
    showFinalResult();
  }
}

function showFinalResult() {
  var elapsed = Math.round((Date.now() - quizState.startTime) / 1000);
  var score = Math.round(quizState.correct / quizState.total * 100);
  showModal({
    title: '练习完成!',
    content: '正确: ' + quizState.correct + '/' + quizState.total +
             '\n得分: ' + score + '分' +
             '\n用时: ' + elapsed + '秒' +
             '\n' + getScoreFeedback(score),
    buttons: ['重新练习', '返回']
  });
}
```

## 七、代码实现注意事项

1. **确保所有交互元素 ≥44×44px**，包括列表项点击区域
2. **使用 touch 事件替代 click 事件**（避免 300ms 延迟）
3. **搜索框自动聚焦需在用户手势触发后调用**（iOS 限制）
4. **代码块使用等宽字体且可横向滚动**
5. **表格在 600px 以下自动转换为卡片列表**
6. **所有弹窗使用底部滑出动画（bottom sheet）**
7. **图片使用懒加载 + 渐进式加载（模糊→清晰）**
8. **页面滚动使用 -webkit-overflow-scrolling: touch**
9. **底部操作栏跟随内容底部，非固定（避免遮挡内容）**
10. **暗色模式跟随系统设置和手动切换**
