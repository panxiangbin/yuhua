## 一、核心字段描述与必填性约束

为保证 Codex 及前端批量处理时格式绝对严密，每一个图片工单任务（Image Job）必须且只能包含以下 **13 个** 核心属性：

| 属性 Key | 物理含义说明 | 必填性 | 类型约束 | 约束规则 |
| :--- | :--- | :--- | :--- | :--- |
| **`imageId`** | 图片全局唯一编码 | 必填 | 字符串 | 必须符合 \`img-b[0-9]{3}-[0-9]{3}\`，如 \`img-b001-002\` |
| **`pageArea`** | 挂载的前台页面区域 | 必填 | 字符串 | 必须落入官方 **8大页面区域**（见下文） |
| **`topicTitle`** | 配图关联的业务标题 | 必填 | 字符串 | 自由字符串，限制 30 字以内 |
| **`imageType`** | 图片的功能分类类别 | 必填 | 字符串 | 必须落入官方 **8大分类大纲**（见下文） |
| **`filename`** | 建议存储的物理文件名 | 必填 | 字符串 | 必须采用严格蛇形格式 \`img_b[0-9]{3}_[type]_[0-9]{3}.webp\` |
| **`prompt`** | 交付 Gemini 的详细提示词 | 必填 | 字符串 | 必须包含主体、视角、构图、色彩和手机留白规范，长度 $\ge 50$ 字 |
| **`negativePrompt`** | 负向过滤词 | 必填 | 字符串 | 标明严禁画面的特征，如水印、低清、文字乱码等 |
| **`styleNotes`** | 风格备注说明 | 必填 | 字符串 | 指明渲染材质（如等角2.5D、微距实拍等） |
| **`priority`** | 图片开发优先级 | 必填 | 字符串 | 只能是 \`P0\`（必出门面）、\`P1\`（高频）、\`P2\`（后补） |
| **`targetAudience`** | 设定图片表达的深度受众 | 必填 | 字符串 | 必须落入官方 **5大受众枚举**（见下文） |
| **`relatedEntryOrSection`**| 绑定底层对象或页面区域 | 必填 | 字符串 | 根据绑定级别，可为真实 entry.id、页面模块ID或占位标识符（见下文） |
| **`mobileCropSafety`** | 手机端裁切安全防线 | 必填 | 字符串 | 标明“是，中心留白”或“否，全幅渲染”等，限制在 30 字以内 |
| **`visualGoal`** | 视觉表达要达到的目标 | 必填 | 字符串 | 详细说明此图是为了防碰撞、说明轨迹还是对比工艺，限制 40 字以内 |

## 二、官方数据枚举字典 (Enums)

### 1. 官方 8 大分类大纲 (imageType)
*   `坐标示意图`, `刀路轨迹图`, `报警情景图`, `对比图`, `对刀步骤图`, `参数仪表图`, `图纸实物对比图`, `流程图`

## 三、绑定级别契约规范 (Binding Levels Contract)

为配合系统的层级化架构（模块导航 $\rightarrow$ 页面区块 $\rightarrow$ 词条详情），`relatedEntryOrSection` 的绑定逻辑分为以下三个级别，任何图片配对必须符合其中之一：

### 1. 词条级绑定 (ENTRY_LEVEL)
*   *适用场景*：直接为 [data.js](file:///F:/AI工作台/cnc_param_quickfinder/data.js)、[kb-extra.js](file:///F:/AI工作台/cnc_param_quickfinder/kb-extra.js) 或 3 个核心包中真实存在的 `entry.id` 配图。
*   *要求*：`relatedEntryOrSection` 的值必须与数据库中的 `id` 100% 对准。

### 2. 区域/模块级绑定 (SECTION_LEVEL)
*   *适用场景*：首页 6 个核心导航大按钮、高级授权包预览页等无物理词条的系统主结构。
*   *合法枚举值*：
    *   `entry-study` (首页新手闯关大类导航)
    *   `entry-gcode` (首页编程指令大类导航)
    *   `entry-alarm` (首页故障诊断大类导航)
    *   `entry-param` (首页切削参数大类导航)
    *   `entry-tooling` (首页刀具选用大类导航)
    *   `entry-calc` (首页快速计算器大类导航)
    *   `premium-preview-tc4` (授权预览区面板)

### 3. 系统备用占位绑定 (PLACEHOLDER_LEVEL)
*   *适用场景*：用于批量备用教学图、系统全局背景板挂载、或尚未完成 entries 录入的虚拟占位点。
*   *格式*：必须以 `extra-` 或 `temp-` 为前缀，如 `extra-geom-001`。
