# 进阶使用指南

> 本指南面向已经会使用基础搜索、知识地图和图库的用户。目标不是介绍“在哪里点”，而是帮助高级用户把平台用得更快、更稳、更适合自己的工作习惯。

---

## 一、高效搜索技巧

### 技巧1：用关键词组合提高准确率

普通搜索可以只输入一个词，但高级用户建议使用组合关键词。组合关键词越接近实际问题，结果越准确。

常用写法：

```text
G54 对刀
G41 取消
铝合金 进给
薄壁件 变形
主轴 报警
G02 IJK
```

例如只搜 `G54`，结果可能包含坐标系、对刀、偏置、案例等多类内容；如果搜 `G54 对刀`，系统会优先显示和工件坐标系设定、试切对刀相关的内容。

### 技巧2：先搜大词，再用筛选缩小范围

当你不确定准确名称时，先搜大词。例如：

```text
圆弧
```

然后用分类筛选选择“G代码”或“编程基础”，再找到 G02/G03、IJK、R 编程相关内容。这个方法适合记不清代码，但记得概念的情况。

### 技巧3：用同义词扩大搜索范围

数控资料里同一个意思常有不同叫法。比如：

| 常见说法 | 可尝试关键词 |
|---|---|
| 刀补 | 刀具补偿、G41、G42、G40 |
| 原点 | 工件原点、工件坐标系、G54 |
| 回参考点 | 回零、机械零点、参考点返回 |
| 圆弧 | G02、G03、IJK、R 编程 |
| 进给 | F 值、每齿进给、切削参数 |

搜索不到时，不要马上判断资料没有，先换一种说法。

### 技巧4：建立自己的高频搜索词

每个岗位的高频搜索词不同。建议用户根据工作内容整理 10-20 个常用词：

- 编程员：G54、G41、G42、G02、G03、G81、G83、G71、G76。
- 操机人员：对刀、回零、报警、刀补、主轴、进给保持、程序启动。
- 工艺人员：铝合金、不锈钢、薄壁件、螺纹、钻孔、粗加工、精加工。
- 维修人员：伺服报警、主轴报警、参数、限位、急停、润滑。

把这些高频词收藏或放到首页快捷入口，可以明显减少重复输入。

## 二、分类筛选的高级用法

### 1. 查询代码时的筛选顺序

查询 G/M 代码时，建议按下面顺序：

1. 搜索代码，例如 `G83`。
2. 筛选“G代码”。
3. 如果有系统差异，再筛选 FANUC、西门子、三菱等。
4. 进入详情后重点看格式、参数、图解和常见错误。

### 2. 查询报警时的筛选顺序

报警查询建议优先使用报警号。如果不知道报警号，再用现象词。

```text
伺服 偏差
主轴 不转
刀库 报警
限位 报警
```

报警结果页建议优先看“排查步骤”，不要只看报警解释。很多报警的真正价值在于告诉你先查哪里、后查哪里。

### 3. 查询工艺时的筛选顺序

工艺类内容建议按照“材料 + 加工方式 + 问题”来查。

示例：

```text
铝合金 铣削 毛刺
不锈钢 钻孔 断刀
薄壁件 铣削 变形
螺纹 加工 烂牙
```

这种写法比只搜“铣削参数”更贴近现场问题。

## 三、收藏夹进阶管理

### 收藏不是仓库，而是工具箱

收藏夹如果什么都放，最后就会变成第二个资料库。建议按用途收藏：

1. **急用类**：报警排查、对刀步骤、回零操作。
2. **高频类**：常用 G/M 代码、常用材料参数。
3. **易错类**：刀补、坐标系、循环指令、宏变量。
4. **培训类**：新人必学路线、操作规范、典型案例。

### 每周整理一次收藏

建议每周花 5 分钟整理收藏：

- 删除已经不常用的内容。
- 把同类知识归到一个专题。
- 把近期频繁查询的内容加入收藏。
- 把收藏里的过期资料替换成新版本。

### 典型收藏清单示例

**编程员收藏清单**：

- G54-G59 工件坐标系
- G41/G42/G40 刀具半径补偿
- G02/G03 圆弧插补
- G81/G83 钻孔循环
- 常用 M 代码表
- 程序检查清单

**操机人员收藏清单**：

- 试切对刀步骤
- FANUC 面板常用按键
- 回零操作流程
- 常见报警排查
- 刀具磨损图解
- 安全操作注意事项

## 四、学习路径进阶用法

### 1. 不同人群使用不同路线

不要所有人都从第一课学到最后。高级用户应按角色选择路线。

| 用户类型 | 推荐路线 |
|---|---|
| 零基础学生 | 入门路线，从机床和坐标开始 |
| 新操机人员 | 操作路线，重点学回零、对刀、面板、报警 |
| 编程员 | 编程路线，重点学 G/M 代码、刀补、循环、案例 |
| 工艺人员 | 工艺路线，重点学材料、刀具、参数、装夹 |
| 维修人员 | 排故路线，重点学报警、参数、机械电气基础 |

### 2. 用学习地图检查知识盲区

如果你已经工作多年，不需要按路线从头学。可以打开知识地图，快速检查自己哪些模块薄弱。

例如一个铣床编程员可能对 G01、G02、刀补很熟，但对宏程序、五轴、机床报警不熟。把不熟的模块标记为“待学习”，比盲目刷资料更有效。

### 3. 把学习路径变成培训计划

车间主管可以这样用：

1. 给新人指定“入门路线”。
2. 第一周学习机床结构、回零、安全操作。
3. 第二周学习对刀、G54、基础程序。
4. 第三周学习 G00/G01/G02/G03。
5. 第四周学习报警排查和典型案例。
6. 每周检查收藏和学习记录。

这样平台不只是个人工具，也能成为车间培训资料库。

## 五、图库的进阶用法

### 1. 用图片做“第一解释”

高级用户在整理资料时，建议每个难点都配一张核心图。尤其是这些内容：

- G02/G03 圆弧方向。
- G41/G42 刀补方向。
- G54-G59 坐标系。
- 试切对刀步骤。
- G71/G72/G73 循环路线。
- 顺铣/逆铣区别。
- 刀具磨损类型。
- 薄壁件变形原因。

图的作用不是装饰，而是降低理解成本。

### 2. 用对比图学习易混知识

易混知识最适合用对比图：

| 易混内容 | 推荐图解方式 |
|---|---|
| G02 / G03 | 同一圆弧上用箭头标方向 |
| G41 / G42 | 同一路径左右补偿对比 |
| 顺铣 / 逆铣 | 刀具旋转方向和进给方向对比 |
| G81 / G83 | 普通钻孔和深孔啄钻动作对比 |
| G54 / 机床坐标 | 两个坐标系叠加示意 |

### 3. 图片命名要规范

如果后续继续扩充图库，建议命名统一：

```text
G02_G03_圆弧方向示意图.png
G41_G42_刀补方向对比图.png
G54_工件坐标系示意图.png
G83_深孔啄钻动作图.png
```

命名规范后，搜索和维护都会轻松很多。

## 六、快捷键大全

> 如果平台主要面向电脑和局域网使用，快捷键能显著提升老用户效率；如果是手机端，可把这些快捷操作转成底部按钮或长按菜单。

| 快捷键 | 功能 | 使用场景 |
|---|---|---|
| Ctrl + F | 快速搜索 | 任意页面直接查资料 |
| Ctrl + D | 收藏当前内容 | 保存常用代码、报警、图片 |
| Ctrl + H | 打开最近查看 | 回到刚刚查过的内容 |
| Ctrl + B | 返回首页 | 快速回到主入口 |
| Ctrl + K | 聚焦全局搜索框 | 类似软件命令入口 |
| Esc | 关闭弹窗或大图 | 查看图片后快速返回 |
| ← | 上一个内容 | 连续浏览搜索结果 |
| → | 下一个内容 | 连续浏览搜索结果 |
| Alt + 1 | 首页 | 快速切换视图 |
| Alt + 2 | 学习地图 | 快速进入学习路线 |
| Alt + 3 | 工作区 | 快速进入查询区 |
| Alt + 4 | 图库 | 快速进入图文资料 |
| Alt + 5 | 收藏 | 快速打开收藏夹 |

## 七、数据管理与备份

### 1. 备份收藏和历史

收藏、最近查看、学习进度都是用户长期使用后积累的数据，建议定期备份。

操作建议：

1. 进入“设置”。
2. 打开“数据管理”。
3. 点击“导出数据”。
4. 保存备份文件到本地安全目录。

如果平台部署在车间公共电脑上，建议每周备份一次，避免浏览器清理或系统重装导致数据丢失。

### 2. 恢复数据

当更换电脑或重新部署时：

1. 进入“设置—数据管理”。
2. 点击“导入数据”。
3. 选择之前导出的备份文件。
4. 确认恢复收藏、历史和学习进度。

### 3. 清理缓存

当软件运行变慢，或图片加载异常时，可以清理缓存：

1. 进入“设置—数据管理”。
2. 点击“清除缓存”。
3. 重新打开平台。

注意：清除缓存前先确认收藏和学习数据是否需要备份。

## 八、性能优化建议

### 1. 图片多时保持页面轻量

图库和图文详情页会有大量图片，建议：

- 首屏图片正常加载。
- 首屏以下图片延迟加载。
- 图片提前设置宽高，减少页面跳动。
- 缩略图和大图分开，不要列表页直接加载原图。

### 2. 搜索输入要防抖

用户输入关键词时，不要每输入一个字就立即执行完整搜索。建议设置 200-300 毫秒防抖，让搜索更流畅。

### 3. 大列表使用虚拟滚动

如果搜索结果很多，不要一次渲染几千条。只渲染当前可见部分，用户滚动时再加载更多。

### 4. 首页不要放太多实时统计

统计数字可以增加专业感，但不要影响打开速度。首页更重要的是入口清楚、搜索快。

## 九、高级用户工作流建议

### 编程员工作流

```text
接到图纸 → 搜加工案例 → 查相关 G 代码 → 收藏易错指令 → 编程 → 检查刀补/坐标/安全高度
```

### 操机人员工作流

```text
开机 → 回零 → 对刀 → 查程序注意事项 → 加工中遇到报警搜索 → 收藏处理方法
```

### 工艺人员工作流

```text
分析材料 → 查切削参数 → 查刀具建议 → 看类似案例 → 制定工艺 → 记录验证结果
```

### 车间培训工作流

```text
指定学习路线 → 新人按模块学习 → 收藏重点 → 每周复盘 → 常见问题沉淀为案例
```

## 十、进阶使用原则

1. 搜索要具体，不要只搜大词。
2. 收藏要克制，只放真正常用的内容。
3. 学习要按路线，不要被资料数量带乱。
4. 图片要服务理解，不要只追求数量。
5. 报警排查要按步骤，不要只看结论。
6. 工艺参数只能做参考，必须结合机床、刀具、材料和装夹判断。
7. 平台是工作助手，不是替代经验；最好的用法是“平台给方向，现场做验证”。
