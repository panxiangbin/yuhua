# 测试用例文档

## 测试环境

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 7/8/10/11，重点测试 Windows 10/11 |
| 浏览器 | Chrome / Edge / Firefox，补充 360极速模式 |
| 手机端 | Android Chrome、iOS Safari、微信内置浏览器 |
| 内存 | 最低 4GB，推荐 8GB+ |
| 硬盘 | 2GB可用空间，推荐 SSD |
| 数据规模 | 42,000+知识条目，125张以上图片 |

## 优先级定义

| 优先级 | 说明 |
|---|---|
| P0 | 核心阻塞，必须通过 |
| P1 | 重要功能，发布前必须修复 |
| P2 | 一般问题，可排期 |
| P3 | 优化建议 |

## 7. 缺陷等级定义

| 缺陷等级 | 说明 | 示例 |
|---|---|---|
| Blocker | 阻塞发布 | 首页白屏、核心数据无法加载 |
| Critical | 严重问题 | 搜索错误、详情打不开 |
| Major | 重要问题 | 收藏失效、图片大量加载失败 |
| Minor | 一般问题 | 个别样式错位、提示不清 |
| Trivial | 轻微问题 | 文案优化、动画细节 |
