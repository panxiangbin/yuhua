## 5. 控制台 / 运行时报错清单

页面加载时控制台表面上是干净的——因为**异常发生在 async 函数里被静默吞掉**，这正是最危险的地方。用错误捕获器实测出3处独立崩溃点，全部是"JS 引用了 HTML 改版后已删除的元素"：

| # | 报错 | 位置 | 炸掉的功能链 |
|---|---|---|---|
| E1 | `TypeError: Cannot set properties of null (setting 'innerHTML')` | `renderHeroMetrics` app.js:798，引用不存在的 `#hero-metrics` | `renderAll()` 中断 → `bootstrap()` 死在第1662行 → **hash路由从未注册**(R1/R2)、工作区/图库/知识库/访问中心首轮渲染全跳过、`initAccess` 未执行、核心知识包自动加载未执行、知识树/推荐/精选图/启动台统计全未初始化(M2/R8) |
| E2 | `TypeError: Cannot set properties of null (setting 'textContent')` | `renderWorkspace` app.js:832，引用不存在的 `#workspace-status` | 每次进工作区/搜索输入都崩 → 结果列表永远空白(R3) |
| E3 | `TypeError: Cannot set properties of null (setting 'textContent')` | `renderDetail` app.js:920，引用不存在的 `#detail-risk`（后续 921/931/932 的 `#detail-source` `#detail-image-title` `#detail-image-caption` 同样不存在） | 详情渲染中途死亡 → 风险徽章/来源/配图/相关推荐丢失(R4) |
