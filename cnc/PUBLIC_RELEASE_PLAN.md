# 数控学习站长期公网版方案

## 目标

- 长期稳定公网访问
- 谁拿到网址谁就能看
- 手机访问稳定
- 后续更新简单

## 当前最合适的形式

这是一个标准静态站点，最适合直接部署到：

- `Cloudflare Pages`
- `GitHub Pages`
- `Vercel`
- `Netlify`

其中当前最推荐的是 `Cloudflare Pages`，因为稳定、适合静态站、后续也容易绑正式域名。

## 为什么现在可以做成公开版

- 页面已经是纯前端静态结构
- 不依赖数据库
- 不依赖登录系统
- 不依赖服务器端接口
- 手机端样式已经单独适配

所以它天然适合做成“别人点网址就能看”的网站。

## 更新流程

后续推荐流程：

1. 我继续在本地改内容
2. 你保留同一个公网项目
3. 每次有新版本时重新发布
4. 原来的网址不变，内容自动变新

## 性能原则

为了保证手机端稳定，后续继续遵守这几条：

- 首页只放轻量内容
- 大知识库按需加载
- 图片按批次逐步接入
- 不把全部大图一次性堆到首屏

## 下一阶段建议

1. 继续补教学图片
2. 继续补知识库内容
3. 选定一个正式公网托管平台
4. 完成第一次正式发布
5. 有需要再绑定自己的域名
