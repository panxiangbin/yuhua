## 一、车间风险预防策略

数控操机现场的核心痛点是“撞机”。很多事故不是因为操作工不懂指令格式，而是因为在按下循环启动（Cycle Start）前没有逐项核对状态（例如对完刀没有在 G54 中保存，或者 H 长度偏置值指错刀具）。

我们在 [entry_warning_checklist_draft_20260706.json](file:///F:/AI工作台/cnc_param_quickfinder/gemini_output/entry_warning_checklist_draft_20260706.json) 中为 **100+ 核心条目**（包括 G代码、M代码、报警自排障、材料切削等）批量生成了检查项（Checklist）和风险等级（Warning Level），这构成了系统向高精度“生产辅助工具”转型的坚实底座。

## 二、典型高风险指令设计规范

为了在操机人员点击详情时起到明显的警醒作用，我们对以下四类高危动作设定了特异性检查清单：

### 1. 坐标系设定类 (G54 - G59 / 回零 / 对刀)
*   *风险等级*：**高**
*   *警示文案*：坐标系偏置错误是车间撞刀的头号元凶！未回参考点前严禁执行快速定位。
*   *强制检查点*：
    1.  机床零点偏置寄存器中输入的 X/Y/Z 物理测量值是否已确认并保存？
    2.  是否执行了手轮模拟轨迹（Dry Run）或单段（Single Block）核对第一点位置？
    3.  主轴安全高度（Z轴起点）是否设定在工件表面 +50mm 以上？

### 2. 刀补偏置类 (G43 / G41 / G42)
*   *风险等级*：**高**
*   *警示文案*：刀具补偿的切入段若无建立距离，或者在死角退刀，会导致程序直接报错甚至强制扎刀。
*   *强制检查点*：
    1.  刀号（T）与长度偏置号（H）/ 半径偏置号（D）是否严格一致？
    2.  G41/G42 建立半径补偿的引入线长度是否大于刀具半径值？
    3.  新程序换刀后，是否使用卡尺物理测定确认了当前的 Z 轴偏置？

### 3. 主轴与进给指令 (M03 / M04 / G94 / G95)
*   *风险等级*：**中**
*   *警示文案*：转速和进给速度偏高会导致刀具瞬间崩断；偏低则会导致粘刀甚至排屑不畅烧刀。
*   *强制检查点*：
    1.  计算出的 S 值（主轴转速）与 F 值（进给量）是否考虑了当前的材料硬度与主轴刚性？
    2.  首件切削时，主轴与进给倍率旋钮是否已调低至 30% - 50% 进行安全试切？

### 4. 故障报警处置类 (超程限位 / 伺服放大器)
*   *风险等级*：**高**
*   *警示文案*：伺服放大器等强电故障时严禁强行多次通电！超程释放时必须认准手轮反向摇出。
*   *强制检查点*：
    1.  物理确认了该轴的绝对行程方向？严禁朝超程极限方向继续摇动。
    2.  在操作电气柜释放按钮前，是否已经物理切断了主轴的传动？
