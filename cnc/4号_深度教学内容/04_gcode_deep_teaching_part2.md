# G20：英制单位 / Inch Input

## 1. 指令名称
- **中文名称**：英制单位
- **英文名称**：Inch Input
- **代码编号**：G20

## 2. 功能说明
G20（英制单位 / Inch Input）的核心作用是：指定后续尺寸按英寸解释，适合英制图纸和英制程序。现场使用时不要只背代码名字，要把它还原成机床动作来理解：刀具要移动到哪里，移动过程中是否切削，是否受当前坐标系、平面、刀补、进给和模态状态影响。本条按FANUC加工中心常见教学口径整理，实际使用仍需核对本机系统说明书。 新手学习本指令时，重点不是把格式背下来，而是知道它会改变什么状态、会让刀具产生什么动作、执行前要检查哪些条件。把这个指令放进程序之前，要先确认图纸基准、G54零点、刀具补偿、安全高度和当前模式是否正确。

## 3. 语法格式
- **标准格式**：`G20 X__ Y__ Z__ F__ ;`
- **变体格式**：可与G90/G91、G17/G18/G19、G54-G59、F、S、H、D等状态配合，具体按功能判断。

## 4. 参数详解
- **X/Y/Z**：常见坐标参数，是否有效取决于该指令功能
- **P/Q/R**：循环、时间、角度、次数或半径参数，含义依系统确认
- **F/S/H/D**：进给、主轴、刀长、刀径相关参数，按语境使用

## 5. 使用场景
1. 英制图纸、海外程序、英制夹具时，用来减少手写程序并保证动作一致。
2. 新程序试切时，用于验证G20相关动作是否和图纸、坐标、刀具一致。
3. 批量加工或重复工序中，用于提高程序可读性和现场调整效率。

## 6. 代码示例
**示例1：**
```gcode
%
O2001 (G20基础用法)
G21 G90 G17 G54
G20
G00 X0 Y0 Z50.
M30
%
```

**示例2：**
```gcode

S2000 M03
G00 X10. Y10. Z5.

G01 Z-1. F100.
G01 X40. F250.

%
```

**示例3：**
```gcode

G20
G00 X20. Y0 Z20.
G00 Z80.
M30
%
```

## 7. 常见错误
- **只背代码不看状态**：现象：程序中写了G20，但刀具动作和预期不一致，可能出现位置偏移、报警或加工尺寸不对。原因：没有检查当前G90/G91、G17/G18/G19、G54、刀补和进给状态。解决：执行前先读安全行，确认坐标系、平面、补偿和进给。
- **忽略系统差异**：现象：同一段含G20的程序在另一台机床上无法运行，或动作含义不同。原因：G20在FANUC、SIEMENS、三菱或厂家定制系统中格式不同。解决：外来程序必须先按本机说明书核对，再模拟和空运行。
- **没有做安全验证**：现象：程序看似格式正确，但第一次运行时发生接近夹具、超程、孔深错误或刀补错误。原因：未进行图形模拟、空运行、单段低倍率验证。解决：新程序必须先模拟，首件加工用低倍率观察关键动作。

## 8. 注意事项
1. 使用G20前先确认当前坐标系和工件零点。
2. 外来程序必须按本机系统说明书核对，不允许直接上机。
3. 首件加工建议单段、低倍率、手放进给保持附近。
4. 涉及Z向、快移、刀补、固定循环时要额外谨慎。
5. 程序修改后必须重新模拟或空运行，不能只凭肉眼感觉安全。

## 9. 系统差异
- **FANUC**：本条按常见FANUC口径说明，但不同0i、31i、车床、加工中心和系统选项会有差异。
- **SIEMENS**：常用写法可能为G0、G1、循环Cycle或高层指令，部分FANUC代码没有直接同名功能。
- **三菱**：多数字母格式接近FANUC，但固定循环、宏、参数开关和厂家PLC定义可能不同。
- **教学提醒**：知识库应把通用指令和厂家自定义指令分开标识，避免新手照抄。

## 10. 实战技巧
- 老师傅看G20时，先看它前一行和后一行，因为模态状态经常藏在前文。
- 第一次跑程序，不要只盯屏幕坐标，要同时看刀具、工件、夹具三者距离。
- 能用图形模拟先确认大方向，再用空运行确认机床真实动作。

## 11. 相关指令
G90/G91、G17/G18/G19、G54-G59、M03/M05

## 12. 练习题
1. **选择题**：使用G20前最先应该确认什么？

B. 操作员今天是否熟练

D. 机床外壳颜色  
**答案**：A。解析：G代码受坐标系、平面、刀补、进给和模态状态影响，先确认状态才谈运行。

2. **选择题**：外来程序中出现G20，本机说明书没有对应说明，正确做法是？  
A. 直接运行  
B. 删除所有安全行

D. 把进给调到最大  
**答案**：C。解析：没有确认定义的G代码可能是厂家自定义或保留代码，直接运行有风险。

3. **编程题**：请写一段安全调用G20的程序框架，要求包含G21、G90、G17、G54、安全Z高度、主轴启动、低倍率试切提示和M30结束。

# G33：螺纹切削 / Thread Cutting

## 2. 功能说明
G33（螺纹切削 / Thread Cutting）的核心作用是：部分系统使用G33进行主轴同步螺纹切削，含义与G32相近。现场使用时不要只背代码名字，要把它还原成机床动作来理解：刀具要移动到哪里，移动过程中是否切削，是否受当前坐标系、平面、刀补、进给和模态状态影响。本条在不同系统、不同机型上差异较大，教学时必须结合机床说明书、系统选项和机床厂家PLC定义确认。 新手学习本指令时，重点不是把格式背下来，而是知道它会改变什么状态、会让刀具产生什么动作、执行前要检查哪些条件。把这个指令放进程序之前，要先确认图纸基准、G54零点、刀具补偿、安全高度和当前模式是否正确。

- **F**：进入补偿时使用的进给速度

## 5. 使用场景
1. 轮廓拐角、刀补过渡、精加工时，用来减少手写程序并保证动作一致。
2. 新程序试切时，用于验证G39相关动作是否和图纸、坐标、刀具一致。
3. 批量加工或重复工序中，用于提高程序可读性和现场调整效率。

## 7. 常见错误
- **只背代码不看状态**：现象：程序中写了G39，但刀具动作和预期不一致，可能出现位置偏移、报警或加工尺寸不对。原因：没有检查当前G90/G91、G17/G18/G19、G54、刀补和进给状态。解决：执行前先读安全行，确认坐标系、平面、补偿和进给。
- **忽略系统差异**：现象：同一段含G39的程序在另一台机床上无法运行，或动作含义不同。原因：G39在FANUC、SIEMENS、三菱或厂家定制系统中格式不同。解决：外来程序必须先按本机说明书核对，再模拟和空运行。
- **没有做安全验证**：现象：程序看似格式正确，但第一次运行时发生接近夹具、超程、孔深错误或刀补错误。原因：未进行图形模拟、空运行、单段低倍率验证。解决：新程序必须先模拟，首件加工用低倍率观察关键动作。

## 8. 注意事项
1. 使用G39前先确认当前坐标系和工件零点。
2. 外来程序必须按本机系统说明书核对，不允许直接上机。
3. 首件加工建议单段、低倍率、手放进给保持附近。
4. 涉及Z向、快移、刀补、固定循环时要额外谨慎。
5. 程序修改后必须重新模拟或空运行，不能只凭肉眼感觉安全。

## 9. 系统差异
- **FANUC**：本条按常见FANUC口径说明，但不同0i、31i、车床、加工中心和系统选项会有差异。
- **SIEMENS**：常用写法可能为G0、G1、循环Cycle或高层指令，部分FANUC代码没有直接同名功能。
- **三菱**：多数字母格式接近FANUC，但固定循环、宏、参数开关和厂家PLC定义可能不同。
- **教学提醒**：知识库应把通用指令和厂家自定义指令分开标识，避免新手照抄。

## 10. 实战技巧
- 老师傅看G39时，先看它前一行和后一行，因为模态状态经常藏在前文。
- 第一次跑程序，不要只盯屏幕坐标，要同时看刀具、工件、夹具三者距离。
- 能用图形模拟先确认大方向，再用空运行确认机床真实动作。
