# 04号｜M代码深度教学 Part 1（M00-M19）

> 说明：M代码大量依赖机床厂家PLC和机床选项。本文件按CNC教学与FANUC常见口径整理，自定义M码均标注风险，正式使用必须查本机说明书和M功能表。

# M00：程序无条件停止 / Program Stop

## 1. 指令名称
- **中文名称**：程序无条件停止
- **英文名称**：Program Stop
- **代码编号**：M00

## 2. 功能说明
M00（程序无条件停止 / Program Stop）的作用是：让程序在当前行无条件暂停，等待操作员确认后继续。 M代码不是单纯的文字命令，它往往直接控制主轴、冷却、换刀、夹具、托盘、门锁、液压、气压或PLC辅助输出。本代码按FANUC及常见机床教学口径整理，具体动作仍受机床厂家PLC、参数和互锁条件影响。 新手学习M代码时，要先问三个问题：它控制什么设备，执行前需要满足什么条件，执行完成后有没有反馈信号。现场不能只看程序里写了M00，还要看机床面板、报警状态、气压油压、主轴状态、刀库状态和夹具状态。

## 3. 语法格式
- **标准格式**：`M00 ;`
- **常见变体**：可与S、T、G84、冷却、换刀、夹具动作或PLC等待信号配合，具体取决于本机定义。

## 4. 参数详解
- **无显式参数**：一般单独成段使用。
- **程序状态**：受操作面板、单段、复位和循环启动影响。
- **互锁条件**：是否允许继续运行由机床状态和系统设置决定。

## 5. 使用场景
1. 中途检查、测量、排屑、确认刀具状态时，用于把程序动作和机床辅助机构联动起来。
2. 首件试运行时，用来检查M00执行前后机床状态是否正确。
3. 自动化加工或批量加工中，用来减少人工确认并保证流程一致。

## 6. 代码示例
**示例1：**
```gcode
%
O1000 (M00中途停机检查)
G21 G90 G17 G54
G00 Z50.
M00 (测量关键尺寸)
G00 X0 Y0
M30
%
```

**示例2：**
```gcode
%
O1001 (M00手动排屑)
G21 G90 G54
G00 Z80.
M05
M00 (清理切屑后继续)
S3000 M03
M30
%
```

**示例3：**
```gcode
%
O1002 (M00换夹具确认)
G21 G90 G54
G00 Z100.
M00 (确认夹具已锁紧)
G00 X0 Y0
M30
%
```

## 7. 常见错误
- **不查本机定义就照抄**：现象：程序中执行M00后机床动作和预期不同，可能出现夹具误动作、冷却异常、主轴未停或辅助设备报警。原因：M代码受厂家PLC定义影响，同号M码在不同机床上可能不同。解决：外来程序必须核对本机M代码表，未确认前不得执行。
- **忽略互锁条件**：现象：M00执行后程序停住、报警，或动作没有完成。原因：气压、液压、门锁、主轴停止、刀具夹紧、夹具到位信号不满足。解决：按报警信息和机床状态逐项检查互锁条件，再低速验证。
- **动作顺序错误**：现象：M00写在不合适的位置，导致主轴未停就换刀、冷却未关就测量、程序停止位置不安全。原因：只知道代码名称，不理解它在流程中的前后关系。解决：按安全顺序写程序，先退刀到安全高度，再停主轴、关冷却、换刀或测量。

## 8. 注意事项
1. 使用M00前必须确认本机M代码定义。
2. 涉及主轴、换刀、夹具、托盘、门和机器人时，先看互锁条件。
3. 新程序第一次运行建议单段执行，观察M代码动作是否完成。
4. 外来程序里的M代码不能按经验直接照抄。
5. 常用M代码也会受机床参数和厂家PLC影响，仍需以本机为准。

## 9. 系统差异
- **FANUC**：M代码由CNC基本功能和机床厂家PLC共同决定，M03/M04/M05/M08/M09/M30较常见，自定义码需查机床表。
- **SIEMENS**：常用M功能相近，但循环、PLC辅助功能和通道控制写法可能不同。
- **三菱**：基础M码接近FANUC口径，但自动换刀、托盘、夹具和专机输出常由厂家定义。
- **教学提醒**：知识库必须把“基础常见M码”和“厂家自定义M码”分层显示。

## 10. 实战技巧
- 老师傅看M代码，先看它控制的是主轴、冷却、刀库还是夹具，不会只背编号。
- 遇到陌生M码，先查说明书，再看机床动作，不要在工件旁边直接试。
- 调试M代码时先空机、单段、远离工件和夹具，确认动作方向和完成信号。

## 11. 相关指令
M03/M04/M05、M08/M09、M00/M01、G00/G01

## 12. 练习题
1. **选择题**：外来程序中出现M00，但你不知道本机定义，正确做法是？  
A. 直接运行  
B. 查本机M代码表并单段验证  
C. 把主轴转速调高  
D. 删除所有安全行  
**答案**：B。解析：M代码常由厂家PLC定义，不确认就运行可能触发错误辅助动作。

2. **选择题**：执行M00前最应该关注什么？  
A. 控制对象和互锁条件  
B. 程序名是否好看  
C. 机床颜色  
D. 操作员是否站得远  
**答案**：A。解析：M代码往往控制真实设备，必须确认动作对象、完成信号和安全条件。

# M03：主轴正转 / Spindle CW

## 1. 指令名称
- **中文名称**：主轴正转
- **英文名称**：Spindle CW
- **代码编号**：M03

## 2. 功能说明
M03（主轴正转 / Spindle CW）的作用是：按顺时针方向启动主轴，常用于右手刀具正向切削。 M代码不是单纯的文字命令，它往往直接控制主轴、冷却、换刀、夹具、托盘、门锁、液压、气压或PLC辅助输出。本代码按FANUC及常见机床教学口径整理，具体动作仍受机床厂家PLC、参数和互锁条件影响。 新手学习M代码时，要先问三个问题：它控制什么设备，执行前需要满足什么条件，执行完成后有没有反馈信号。现场不能只看程序里写了M03，还要看机床面板、报警状态、气压油压、主轴状态、刀库状态和夹具状态。

## 3. 语法格式
- **标准格式**：`S____ M03 ;`
- **常见变体**：可与S、T、G84、冷却、换刀、夹具动作或PLC等待信号配合，具体取决于本机定义。

## 4. 参数详解
- **S**：主轴转速，单位通常为r/min，必须在M03/M04前或同段指定。
- **方向**：M03为常见正转，M04为反转，具体方向以主轴端观察和机床定义为准。
- **互锁**：主轴门锁、刀具夹紧、档位、润滑和报警状态会影响启动。

## 5. 使用场景
