# 04号｜FANUC报警详解 Part 2（100-999号报警，25条）

> 安全说明：FANUC报警号会随系统系列、机床类型、厂家PLC和选项差异变化。本文件用于知识库教学和现场排查引导，不替代本机报警说明书。涉及伺服、主轴、电池、限位和电柜检查时，必须由有资质人员处理。

# 报警100：PARAMETER WRITE ENABLE

## 1. 报警编号
**100**

## 2. 报警信息
- **英文信息**：PARAMETER WRITE ENABLE
- **中文说明**：参数写入允许状态打开

## 3. 报警类型
**P/S报警**

## 4. 触发原因
1. 程序格式、地址、数值或模态状态不满足系统要求。
2. 外来程序使用了本机不支持的G/M代码、宏格式或小数点格式。
3. 程序被手工修改后没有重新检查，出现缺地址、错符号、错补偿号。
4. 系统参数、单位、输入格式或选项功能与程序来源机床不一致。

## 5. 排查步骤
1. 先停下程序，记录报警号、程序号、程序段号和当前模式，不要直接改一堆地方。
2. 打开报警画面和程序画面，定位报警发生的那一行，同时查看前后两三行模态状态。
3. 检查地址是否缺失、数字是否超范围、小数点和负号是否合法、F/S/T/H/D是否完整。
4. 确认该G代码、宏语句或固定循环是否为本机系统支持，外来程序尤其要查说明书。
5. 修改后先图形模拟，再空运行，首件用单段低倍率验证。

## 6. 解决方法
1. 程序格式错：按报警行修改地址、数字、小数点、负号或缺失参数。
2. 本机不支持：删除或替换不支持的代码，如高速选项、宏语法或厂家循环。
3. 模态状态错：补齐G90/G91、G17/G18/G19、G40/G49/G80等安全状态。
4. 外来程序错：按本机后处理重新输出，避免手工大面积修补。

## 7. 预防措施
1. 新程序先模拟、空运行、单段低倍率验证。
2. 外来程序必须查本机系统支持情况，不照抄。
3. 每次报警记录报警号、程序段、坐标、刀具和现场状态。
4. 涉及伺服、主轴、电池、限位的报警，禁止带电乱拔插和反复强行复位。

## 8. 真实案例
- **现场案例A**：案例1：某加工中心在首件试运行时出现100报警。操作员没有直接复位，而是记录程序段号，发现问题发生在新修改的程序行。师傅检查前后程序，定位到参数写入允许状态打开相关条件不满足。修改后先模拟，再单段低倍率运行，报警消失。
- **现场案例B**：案例2：另一台机床在批量加工中偶发100报警。维修人员没有只看报警文字，而是把刀具、夹具、程序、坐标和机床状态一起记录。最终发现是外来程序或现场状态变化触发了参数写入允许状态打开。恢复标准流程后，连续加工稳定。

## 9. 相关报警
010、011、030、033、041、G90/G91、G40/G41/G42、G80

## 10. 紧急程度
**警告**。如果报警涉及伺服、主轴、限位、绝对位置或硬件，请先停机并通知有资质人员处理。程序类报警也不要盲目删除代码，应先确认原因。

# 报警300：APC ALARM: NEED ZRN

## 1. 报警编号
**300**

## 2. 报警信息
- **英文信息**：APC ALARM: NEED ZRN
- **中文说明**：绝对位置丢失，需要回零或重新建立参考

## 3. 报警类型
**APC报警**

## 4. 触发原因
1. 绝对编码器电池电压低或断电期间电池失效。
2. 更换电池、拔插反馈线或维修时位置数据丢失。
3. 长期停机后电池耗尽，系统无法确认机床绝对位置。
4. 轴参考点未重新建立，系统要求重新回零或设定原点。

## 5. 排查步骤
1. 不要随意移动轴，先记录报警号、轴名和当前位置。
2. 检查绝对编码器电池电压和电池更换记录，确认是否曾断电拔线。
3. 按本机维修手册执行回零、参考点重建或绝对位置设定流程。
4. 确认软限位、机床坐标、G54和换刀点不会因位置丢失产生风险。
5. 完成后空运行全行程和换刀动作，再恢复加工。

## 6. 解决方法
1. 电池低：按带电更换规范更换电池，防止位置丢失。
2. 位置已丢：按维修手册重建参考点和绝对位置。
3. 维修后报警：检查反馈线和编码器连接，确认轴号对应。
4. 恢复后验证：全程空运行、换刀验证和软限位验证。

## 7. 预防措施
1. 新程序先模拟、空运行、单段低倍率验证。
2. 外来程序必须查本机系统支持情况，不照抄。
3. 每次报警记录报警号、程序段、坐标、刀具和现场状态。
4. 涉及伺服、主轴、电池、限位的报警，禁止带电乱拔插和反复强行复位。

## 8. 真实案例
- **现场案例A**：案例1：春节后开机出现300报警，机床长期断电导致绝对编码器电池失效。维修人员按手册更换电池并重建参考点，随后检查软限位和换刀点，确认没有位置丢失风险。
- **现场案例B**：案例2：维修时拔过反馈线，开机后出现300报警。现场没有直接加工，而是重新建立绝对位置，空运行全行程和换刀动作，确认坐标恢复正常。

## 9. 相关报警
300、306、307、参考点、绝对编码器电池、软限位

## 10. 紧急程度
**停机**。如果报警涉及伺服、主轴、限位、绝对位置或硬件，请先停机并通知有资质人员处理。程序类报警也不要盲目删除代码，应先确认原因。

## 8. 真实案例

# 报警751：SPINDLE ALARM DETECTION

## 1. 报警编号
**751**

## 2. 报警信息
- **英文信息**：SPINDLE ALARM DETECTION
- **中文说明**：CNC检测到主轴放大器报警

## 3. 报警类型
**SP报警**

## 4. 触发原因
1. 主轴负载过大、刀具钝化、切削参数过重或工件夹紧异常。
2. 主轴放大器、电机、传感器、编码器或反馈电缆异常。
3. 主轴冷却风扇、散热、供电或链路通信存在问题。
4. 主轴相关参数、档位、定向或外部互锁条件异常。

## 5. 排查步骤
1. 停止切削并记录主轴转速、负载、刀具、材料、切削参数和放大器报警号。
2. 检查刀具是否磨损、切深切宽是否过大、工件是否松动、主轴是否有异常声音。
3. 断电后检查主轴电机风扇、散热、编码器线、动力线和主轴放大器状态。
4. 核对主轴档位、M03/M04、M19、G96/G97和最高转速限制是否合理。
5. 排除后空转主轴，再轻切削验证，不允许直接恢复重切削。

## 6. 解决方法
1. 切削过载：降低切深、切宽、进给或更换锋利刀具。
2. 主轴硬件异常：检查放大器、电机、风扇、传感器和反馈电缆。
3. 通信或链路异常：检查光缆、串行主轴连接和电源状态。
4. 参数或档位异常：按厂家资料核对主轴参数、档位和定向条件。

## 7. 预防措施
1. 新程序先模拟、空运行、单段低倍率验证。
2. 外来程序必须查本机系统支持情况，不照抄。
3. 每次报警记录报警号、程序段、坐标、刀具和现场状态。
4. 涉及伺服、主轴、电池、限位的报警，禁止带电乱拔插和反复强行复位。

## 8. 真实案例
- **现场案例A**：案例1：某机床重切削时出现751报警，操作员立即停机，没有反复复位。检查发现刀具磨损、负载偏高，同时放大器有对应报警显示。更换刀具并降低切削负载后，先空运行再轻切削验证，报警未再出现。
- **现场案例B**：案例2：设备开机后出现751报警，维修人员断电检查连接器、反馈线、风扇和电源状态，发现相关插头松动或散热异常。处理后按回零、空转、低负载切削顺序验证，避免直接恢复生产。
