# 数控新手学习助手

这是一个手机优先的数控学习与速查网页，适合新手快速查参数、G 代码、报警、量具、工艺换算和学习路线。

## 当前功能

- 按参数号、G/M 代码、关键词快速搜索
- 常用代码、FANUC 参数、报警、量具、图纸符号、工艺换算一站式速查
- 学习路线和常用入口卡片，适合手机上边学边查
- 收藏、最近查看、快捷搜索词
- 参数换算工具
- 图解提示词专题，方便继续批量生成教学配图
- PWA 基础配置，部署后可以更接近轻量网页应用

## 站点结构

- `index.html`：页面入口
- `styles.css`：页面样式
- `app.js`：搜索、跳转、收藏、换算和交互逻辑
- `data.js`：知识库数据
- `manifest.webmanifest`：PWA 配置
- `service-worker.js`：基础缓存
- `DEPLOY.md`：公网部署说明

## 使用方式

直接打开 `index.html` 就能本地试用。

如果想更接近正式网页版预览，可以双击 `preview-local.bat`，然后访问 `http://localhost:8000`。

## 公网发布

当前项目已经按“公开访问版”整理：

- 不需要登录
- 不需要白名单
- 不需要授权页

只要部署到正式托管平台，别人拿到网址就能直接看。
