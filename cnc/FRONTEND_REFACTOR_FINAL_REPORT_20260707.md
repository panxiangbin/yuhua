## 3. 新增功能列表

### 学习系统
- 12 关课程数据的渲染引擎，每关含目标/步骤/错误/练习/小结
- 选择题/判断题/填空题三种题型，即时反馈对错与答案解析
- 学习进度追踪（完成标记、时长统计、阶段进度条）
- 课程导航（面包屑、章节目录、上下关切换、键盘 ← →）
- SVG 图片占位符生成，支持未来替换为真实图片
- 学习数据持久化（LocalStorage）

### 搜索增强
- 实时搜索建议（输入 2 字符触发，前缀/包含两种匹配）
- 键盘导航（↑↓选择，Enter 确认，Esc 关闭）
- 搜索历史管理（自动记录、去重、单条删除、清空）
- 智能拼写纠错（30+ 常见错误映射 + 编辑距离算法）
- 高级筛选面板（分类/难度/图片多条件组合 + 预设保存）
- 全文关键词高亮 + 匹配项导航 + 计数

### 卡片可视化
- 响应式瀑布流布局（2-4 列自适应，虚拟滚动）
- 卡片入场/悬停/展开折叠动画（CSS3 过渡）
- Markdown 富文本渲染（标题/代码/表格/列表/粗斜体/链接/图片）
- GCode 专用代码高亮（蓝色 G 代码、青色 M 代码、橙色坐标轴）
- 18 色标签系统 + 标签云（按权重排序，可变字号）

### 图片系统
- 全屏图片查看器（缩放 25-500%、旋转、拖拽、滚轮、键盘）
- CSS 滤镜（亮度/对比度/灰度/怀旧/饱和度/色相旋转）
- Canvas 图片标注（文字/箭头/矩形、撤销/重做 50 步、PNG 导出）
- 暗色覆盖层 + 毛玻璃效果控制栏

### 分析系统
- 四类事件追踪（页面访问/搜索/点击/停留时间）
- LocalStorage 持久化，上限 1000 条
- 统计仪表盘（统计卡片 + 柱状图 Top 8 + 时间线）

### 性能监控
- Performance API 加载时间测量
- 内存占用监控（Chrome only）
- 性能瓶颈检测（加载 >3s/内存 >100MB/大图 5+）
- FPS 实时监测（rAF 循环）

### 主题系统
- CSS 变量驱动的三主题（浅色/深色/高对比度）
- 自定义主题注册 + 导入导出
- 切换监听回调
- LocalStorage 持久化

### 键盘快捷键
- 任意组合键注册（Ctrl/Alt/Shift/Meta）
- 冲突检测
- 帮助面板（控制台输出）
- 输入框中自动禁用

## 5. 技术债务说明

| 项目 | 说明 | 优先级 |
|------|------|--------|
| 学习数据不完整 | 仅内置 4/12 关示例数据 | 高 |
| Markdown 渲染器简化 | 自实现仅支持常用语法，嵌套可能出错 | 中 |
| Canvas 导出跨域限制 | 非同源图片导出抛安全错误 | 中 |
| 撤销栈内存 | 深拷贝 JSON 快照，大标注集时耗内存 | 低 |
| 无自动化测试 | 全部需手动在浏览器执行 | 高 |
| 分析事件上限 | 1000 条硬限制，长期使用会丢失早期数据 | 低 |
| 主题 CSS 覆盖度 | 部分第三方/未来组件可能未使用 CSS 变量 | 中 |
