# ChatGPT Plus 网页版 - 独立任务2

## 👋 你好，现在给你分配第二个任务

第一个任务（CSS优化）已完成。现在需要你设计一个**空状态提示组件**。

---

## 📋 任务目标

设计并提供完整的HTML + CSS代码，用于"只看带图"筛选后没有结果时的友好提示。

---

## 🎨 设计要求

### 场景
用户在工作区勾选"只看带图"，但当前搜索条件下没有带图内容。

### 风格
- 土黄色温暖风格（`#f3ebde`, `#cf6d36`, `#5d655f`）
- 友好、专业、不冰冷
- 简洁大方，不要太花哨

### 内容结构
1. 图标（可以用emoji或SVG）
2. 主标题（12-18字）
3. 说明文字（30-50字）
4. 操作建议（可选按钮）

---

## 📦 需要你提供

### 1. HTML结构
```html
<div class="empty-state-wrapper">
  <!-- 你的代码 -->
</div>
```

**要求**：
- 语义化HTML
- 可访问性（ARIA标签）
- 响应式友好

---

### 2. CSS样式
```css
/* 空状态组件样式 */
.empty-state-wrapper {
  /* 你的代码 */
}
```

**要求**：
- 居中显示（垂直+水平）
- 最小高度：300px
- 土黄色系配色
- 支持移动端（<640px）

---

### 3. 提供3个不同场景的变体

#### 变体1：无带图结果
```
标题：当前没有找到带图内容
说明：试试取消"只看带图"筛选，或更换搜索关键词
```

#### 变体2：知识库未加载
```
标题：知识库还未加载
说明：点击右上角"加载核心知识"按钮，即可查看1796条专业内容
```

#### 变体3：搜索无结果
```
标题：没有找到相关内容
说明：试试使用更通用的关键词，如"G代码"、"刀具"、"报警"等
```

---

**字体大小参考**：
```css

主标题：20-24px
说明文字：15-16px

```
