# 数控教学图片文件命名规范 (2026-07-06)

本规范为网站首批 3000 张教学图片的命名收录和管理基石，确保 Codex 及前端批量读取时绝对对齐。

## 一、文件名结构定义

所有入库图片统一遵循以下下划线连接的蛇形命名法(snake_case)：

`[前缀]_[批次号]_[分类缩写]_[序列号].webp`

*   **前缀**：固定为 `img`
*   **批次号**：首批统一为 `batch01` / `b001`
*   **分类缩写**：代表图片的功能模板分类（3-6个字母）
*   **序列号**：三位递增的数字，如 `001` 至 `240`
*   **格式扩展名**：统一采用现代 Web 压缩格式 `.webp`

---

## 二、分类前缀缩写字典

| 图片类型 | 缩写前缀 | 适用场景示例 |
| :--- | :--- | :--- |

| **对刀步骤图** | `touchoff` | 寻边器碰碰侧边分中、对刀块测定Z高 |
| **参数仪表图** | `calc` | Vc线速度双曲线函数换算、螺距对照表 |
| **图纸实物对比** | `drawing` | 零件三视图工程符号与金属实物对齐 |
| **流程图** | `flow` | ATC 卡刀强行释放三步骤、手动回零顺序 |

## 三、版本与缩略图管理规范

1.  **高清晰大图 (HD Source)**:
    *   直接存放于 `assets/images/[Category]/` 目录下，最高分辨率限制在 `1024x1024`，采用 webp 75% 压缩率，大小控制在 150KB 以内。
2.  **前台缩略图 (Thumbnails)**:
    *   文件名格式：`[主文件名]_thumb.webp`（如 `img_batch01_coordinate_002_thumb.webp`）。
    *   物理宽度限制为 `150px`，webp 40% 压缩率，大小控制在 10KB 以内，专用于前台列表快速渲染，实现零秒防卡顿。
