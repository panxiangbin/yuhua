# 学习系统规划：数控新手入门路径设计

**文件路径**: `F:\AI工作台\cnc_param_quickfinder\GEMINI_WEB_LEARNING_SYSTEM_PLAN.md`

## 一、 新手用户分层与破冰需求

为了不让新手一上来就被海量信息吓退，我们需要在他们首次打开软件时（或在个人设置里）让他们选择自己的状态，我们将用户分为三层：

1.  **小白层（完全零基础）**
    *   **状态**：纯外行，可能刚进厂，连机床长什么样都没概念。
    *   **最先需要**：消除恐惧感。认识机床基本结构、明白什么是轴（X/Y/Z）、看懂图纸最基础的符号。
2.  **操作层（刚接触机床操作）**
    *   **状态**：能按启动键，会装夹工件，但不知其所以然，不敢改程序。
    *   **最先需要**：明白坐标系怎么回事、工件零点怎么定、怎么安全对刀、基础的刀具常识。
3.  **进阶层（会基本操作但不会编程/调参数）**
    *   **状态**：想学编程拿高薪，想遇到报警能自己解决，而不是总喊师傅。
    *   **最先需要**：G代码/M代码的核心逻辑、主轴/进给的搭配计算、固定循环的用法、报警代码的快速翻译。

## 二、 核心学习顺序（闯关路线）

按照从宏观到微观、从安全到实操的逻辑，我们将那几个核心主题串联成一条单向解锁的路线：

*   **第1关：看图与认路** -> 图纸基础符号（先知道要做成什么样）
*   **第2关：机床的东南西北** -> 坐标与回零（认识机床的绝对参照物）
*   **第3关：告诉机床从哪开始** -> 对刀与工件零点（理解G54-G59，最核心的实操门槛）
*   **第4关：认识你的武器** -> 刀具与切削基础（铣刀、车刀分类，顺铣与逆铣）
*   **第5关：干活的节奏** -> 主轴 / 进给 / 转速（转得快慢和走得快慢的关系）
*   **第6关：让机床动起来** -> G00 / G01 / G02 / G03（点位快速移动与直线/圆弧切削）
*   **第7关：打包的高级动作** -> 钻孔/攻丝类固定循环（G81/G83等，提高效率必学）
*   **第8关：机床的脾气与密码** -> 常见参数概念 & 报警怎么看（进阶必修，懂了就是师傅）

## 三、 每一步的视觉配图策略

车间兄弟们对图像的敏感度远大于文字，配图必须精准：

*   **图纸基础符号**：【实物对比图】左边是图纸符号，右边是加工出来的真实零件局部特写。最直观。
*   **坐标与回零 / 对刀**：【3D空间示意图】用带颜色的箭头（X红、Y绿、Z蓝）在立体空间标出方向。对刀需要【面板按键步骤图】配合机床实拍。
*   **G00/G01/G02/G03**：【动态轨迹图】最好是GIF动图，实线代表切削（G01/02/03），虚线代表快速移动（G00）。
*   **主轴/进给/转速**：【仪表盘与切屑状态图】用仪表盘展示参数变化，配以铁屑形状（断屑好坏）的对比图，说明参数对不对。
*   **固定循环**：【动作拆解流程图】比如G83深孔啄钻，用分步剖面图展示钻头“进-退-进”的完整路径，并在图上直接标注R点、Z底。
*   **报警怎么看**：【情景插画】画一个撞刀或者卡盘没夹紧的卡通示意图，旁边配上机床屏幕的报警红字，降低阅读枯燥感。

## 四、 学习地图页面的 UI 组织方式

我们要给用户一种“今天花5分钟就能学完一节”的轻松感：

1.  **首页显示步数**：同屏最多只显示 3 到 4 个主关卡（比如一屏只显示“初级篇”的内容），滑动才能看后续。
2.  **卡片元素**：每个卡片上只显示：**大标题**（如：对刀到底在对什么）、**预计时长**（如：5分钟）、**当前进度条**、**核心标签**（如：G54/Z轴设定）。
3.  **信息隐藏**：不要一开始就把宏程序、极坐标系、复杂的PMC参数漏出来，这些放在地图最后面的“隐藏关卡”或“高级进修班”里。
4.  **避免文字满屏的绝招**：采用“交互式卡片翻转”或“答题解锁”。看完一张动图，做一道单选题（比如“此时Z轴是正还是负？”），选对了才出下一段文字。

## 五、 新手最容易卡住的 10 个阻塞点及软件内解法

产品设计的核心就是帮用户跨过这些坑：

1.  **绝对坐标与增量坐标（G90/G91）切错**
    *   *软件解法*：提供一个小工具，输入两个点，一键对比显示绝对编程和增量编程写出来的代码差异。
2.  **G00 速度太快导致撞刀**
    *   *软件解法*：在G00词条页加上醒目的红色骷髅头警告，强调“G00走折线不是直线”，并用动图演示撞刀风险。
3.  **转速（S）与进给（F）关系凭感觉**
    *   *软件解法*：直接在学习页嵌入“切削参数计算器”，选好材质和刀具，让用户拖动滑块，看数值怎么联动变化。
4.  **报警代码查不到或看不懂**
    *   *软件解法*：提供“大白话翻译机”。机床报“PS0009”，软件不仅显示官方解释，下面直接跟一句大白话：“你可能坐标系没设对，去检查一下G54”。
5.  **顺铣与逆铣傻傻分不清**
    *   *软件解法*：用两个带动画的齿轮咬合图，直观展示刀刃切入工件时受力的方向不同。
6.  **刀尖圆弧半径补偿（G41/G42）加反方向**
    *   *软件解法*：设计一个“顺着走还是逆着走”的判定小游戏，用左右手掌示意法则进行图文教学。
7.  **固定循环参数（R点，Q值）记不住**
    *   *软件解法*：开发“一键生成器”。用户填入孔深、提刀量，软件自动生成标准G83代码，用户一看就懂Q代表啥。
8.  **分不清机床零点、参考点、工件零点**
    *   *软件解法*：用“家（机床零点）、小区门口（参考点）、你的工位（工件零点）”这种生活化比喻的图文故事来解释。
9.  **攻丝到底该用多大的底孔**
    *   *软件解法*：做一个“底孔速查表”插件，输入M8，直接弹出底孔6.8mm，不讲废话。
10. **小数点忘了打（比如把X10.打成X10）**
    *   *软件解法*：在编程规范章节，设置一个“找茬”小测验，给出两行代码对比，让用户找不同，加深肌肉记忆。
