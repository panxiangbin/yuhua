## 一、使用说明

### 1.1 词典结构

关键词词典按标签维度分为 5 个词表，每个词表由 `{关键词 → [标签ID, 权重]}` 映射组成。权重范围 0-1，表示该词对标签的指示强度。

### 1.2 匹配规则

```
权重≥0.8: 强匹配 (该词几乎唯一指向此标签)
权重0.5-0.8: 中匹配 (常见于此标签但不唯一)
权重<0.5: 弱匹配 (可能出现但指示性弱)

最终标签置信度 = 所有命中关键词权重的平均值 × 命中率因子
命中率因子 = min(命中词数 / 期望最少命中数, 1.0)
```

## 九、词典使用说明

### 9.1 自动分类流程

```
输入: 文件内容 content, 路径 path, 文件名 name

1. 遍历 D1-D6 所有关键词
2. 对每个关键词在 content 中搜索 (大小写不敏感)
3. 记录命中关键词, 按标签维度分组
4. 对每个维度:
   a. 计算总置信度 = avg(命中关键词权重) × 命中率因子
   b. 如果置信度 > 阈值 (默认0.3), 加入候选
   c. 用路径标签加分 (pathTag × 0.6)
   d. 用文件名标签加分 (fileNameTag × 0.5)
5. 输出: { dimension: [ {tagId, confidence}, ... ] }
```

### 9.2 权重调整

- 权重 0.3 为最低有效阈值（权重低于此的匹配将被忽略）
- 同一维度下，取置信度最高的标签作为主标签
- 置信度≥0.6 的标签为"高信标签"，可用于推荐和筛选
- 置信度在 0.3-0.6 的标签为"建议标签"，仅供参考
- 用户手动添加的标签自动设为 0.9 置信度
