API 使用说明

window.CncCalculatorSuite.setActive(id)：切换计算器，例如 speed、feed、arc。

window.CncCalculatorSuite.calculate(id, values)：传入指定计算器 ID 和表单值，返回计算结果。

window.CncCalculatorSuite.getHistory(id)：读取某个计算器历史；不传 ID 返回全部历史。

window.CncCalculatorSuite.clearHistory(id)：清空某个计算器历史；不传 ID 清空全部。
