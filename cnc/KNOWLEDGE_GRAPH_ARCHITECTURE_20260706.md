## 阶段1：知识图谱架构设计

### Part A：知识本体设计

#### 1.1 核心实体定义

知识图谱的核心实体设计围绕数控加工全生命周期展开，目标是构建一个可推理、可扩展、可视化的结构化知识网络。

**实体类型清单**：

1. **G代码实体**
   - 属性：代码编号、功能名称、语法格式、参数列表、系统兼容性
   - 关系：继承关系、互斥关系、配合关系
   - 实例数量：约120个

2. **M代码实体**
   - 属性：代码编号、功能名称、触发时机、硬件要求
   - 关系：执行顺序、依赖关系
   - 实例数量：约100个

3. **机床参数实体**
   - 属性：参数编号、参数名称、取值范围、系统版本
   - 关系：关联参数、冲突参数
   - 实例数量：约500个

4. **报警代码实体**
   - 属性：报警编号、报警信息、严重等级、触发条件
   - 关系：关联参数、前置报警、后续报警
   - 实例数量：约300个

5. **刀具实体**
   - 属性：刀具类型、材质、几何参数、适用材料
   - 关系：配套刀柄、适用工艺、切削参数推荐
   - 实例数量：约200个

6. **加工工艺实体**
   - 属性：工艺名称、工艺类型、适用场景、参数范围
   - 关系：前置工艺、后续工艺、配套刀具
   - 实例数量：约150个

7. **材料实体**
   - 属性：材料名称、材料分类、物理特性
   - 关系：适用刀具、推荐工艺
   - 实例数量：约100个

8. **案例实体**
   - 属性：案例名称、零件类型、难度等级
   - 关系：使用的G代码、使用的刀具、应用的工艺
   - 实例数量：约80个

#### 1.2 关系类型定义

1. **层级关系** (is_a, part_of)
   - 应用：学习路径构建
   - 实现：树形结构+路径压缩

2. **功能关系** (requires, conflicts_with, cooperates_with)
   - 应用：程序合法性检查
   - 实现：邻接表+关系缓存

3. **因果关系** (causes, solves, prevents)
   - 应用：报警诊断
   - 实现：有向图+贝叶斯推理

4. **时序关系** (before, after, during)
   - 应用：工艺流程规划
   - 实现：时间轴标注

5. **相似关系** (similar_to, equivalent_to, alternative_to)
   - 应用：替代方案推荐
   - 实现：相似度矩阵+协同过滤

### Part B：知识图谱存储方案

#### 2.1 存储架构选型

**最终选择**：内存图 + IndexedDB持久化

**选择理由**：
1. 符合纯前端架构
2. 支持file://本地运行
3. 查询性能满足需求（<5000节点）
4. 实现复杂度可控
5. 便于分层加载优化

#### 2.2 数据结构设计

核心数据结构：
- 节点存储：Map<id, Node>
- 边存储：Map<id, Edge>
- 类型索引：Map<type, Set<id>>
- 属性索引：Map<property, Map<value, Set<id>>>
- 全文索引：倒排索引+TF-IDF

#### 2.3 查询接口设计

提供统一的查询接口：
- `queryNodes(filters)` - 节点查询
- `traverse(startId, relationTypes, direction, maxDepth)` - 关系遍历
- `recommend(basedOnNodeId, limit)` - 推荐查询
- `findPath(from, to)` - 路径查询

### Part C：知识图谱可视化设计

#### 3.1 可视化需求分析

**用户角色**：
1. 新手学习者 - 清晰知识地图+推荐学习路径
2. 经验工程师 - 快速搜索+关系探索
3. 系统管理员 - 数据全景+质量监控

#### 3.2 图布局算法选择

- 总览：网格布局（性能优先）
- 探索：力导向布局（直观）
- 路径：层次布局（清晰）
- 推荐：圆形布局（紧凑）

#### 3.3 交互设计规范

- 导航交互：平移、缩放、回中心
- 节点交互：单击选中、双击展开、悬停预览
- 边交互：悬停高亮、单击显示详情
- 性能优化：降采样、LOD、WebGL渲染

## 附录：技术实现

### A. KnowledgeGraph类核心方法

详见 `KnowledgeGraph.js` 文件，包含：
- `addNode()` - 添加节点
- `addEdge()` - 添加关系
- `queryNodes()` - 查询节点
- `traverse()` - 关系遍历
- `recommend()` - 推荐功能
- `saveToIndexedDB()` - 持久化
- `loadFromIndexedDB()` - 加载

### B. 使用示例

```javascript
// 创建实例
const kg = new KnowledgeGraph();

// 添加G54节点
kg.addNode({
  type: 'GCode',
  label: 'G54',
  properties: { 
    code: 'G54', 
    function: '工件坐标系1', 
    system: 'FANUC' 
  }
});

// 查询G代码
const gcodes = kg.queryNodes({ type: 'GCode' });

// 遍历关系
const related = kg.traverse('gcode_g54', ['requires'], 'outgoing', 2);

// 推荐
const recommendations = kg.recommend('gcode_g54', 5);

// 持久化
await kg.saveToIndexedDB();
```
