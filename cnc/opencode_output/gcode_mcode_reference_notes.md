## 不同系统间差异较大的代码

以下代码在不同CNC系统中用法有显著差异，使用时需注意：

| 代码 | 差异说明 |
|------|----------|
| **G50** | FANUC中为主轴最高转速限制/缩放取消；其他系统中可能不同 |
| **G74** | FANUC铣床为左旋攻丝，车床为深孔钻；其他系统定义可能不同 |
| **G77/G78/G79** | 这些代码在不同系统（FANUC/西门子/三菱）中功能定义差异较大，部分系统不存在 |
| **G92** | FANUC中用于坐标系设定/转速限制；部分系统中用于螺纹切削循环 |
| **G160** | 非标准代码，仅在特定系统中使用 |
| **M06** | 换刀逻辑在不同系统中实现方式不同（有些要求T在前，有些要求M06在前） |
| **M19** | 主轴定向功能在FANUC和西门子中控制方式不同 |
| **M29** | 刚性攻丝模式，FANUC用M29激活，其他系统可能用不同代码 |
| **M70-M79** | 机床厂家自定义扩展代码，各厂家定义差异极大 |
| **M85-M95** | 非标准代码，在不同机床中含义不同 |

## 标记为待人工复核的内容

以下内容基于通用CNC知识编写，建议由专业人员进行复核：

1. **G45-G48（刀具偏置增加/减小）**：这些代码在FANUC 0i系列中已较少使用，不同版本的FANUC系统实现有所不同
2. **G77/G78/G79**：这些代码在标准FANUC 0i/16i/18i中不是标准代码，部分对应于G92螺纹循环，需对照具体机床手册确认
3. **M23/M24**：螺纹退刀倒角控制在FANUC车床系统中具体实现细节需核实
4. **M31**（互锁旁路）：实际使用中存在安全风险，不同机床实现方式差异大
5. **M90-M95**：这些在标准FANUC系统手册中通常未定义，为机床厂家自定义区
6. **G36/G37（自动刀具补偿）**：具体实现依赖机床硬件配置（如对刀仪），非所有FANUC系统标配
7. **G160**：非ISO标准G代码，仅在特定厂家系统中存在
8. **扩展M代码（M63-M68, M74-M79, M87-M89）**：地址分配和功能完全依赖机床厂家，无法给出通用精确描述

## 数据质量说明

- 所有 `commonMistakes` 内容为基于多年现场经验的整理
- 数值参数和具体编程格式未纳入本参考数据，如需详细格式请参考对应FANUC编程手册
- 本数据以FANUC系统为主要参考，兼顾通用兼容性
