# 数控工程师工作平台 - 5分钟快速上手

## 欢迎使用

欢迎使用《数控工程师工作平台》。它不是普通资料网页，而是为数控编程、操机、工艺学习和现场速查设计的专业工作平台。平台整合 42,000+ 数控知识条目、125 张教学图片、知识地图、智能推荐和快速搜索功能，目标很直接：新手能按路线学，老手能快速查，车间现场遇到问题时不用到处翻手册、问师傅、搜零散资料。

你可以把它理解成一个“数控资料工作台”：学习时是课程路线，编程时是 G/M 代码速查，报警时是排查助手，做工艺时是参数和案例参考库。

## 核心功能一：知识库查询 📚

### 适合场景

知识库查询适合查 G 代码、M 代码、FANUC 常用指令、机床报警、坐标系、对刀、刀具、切削参数、CAM 软件和加工案例。

### 使用方法

1. 在首页点击 **“知识库查询”**，或进入 **“工作区”**。
2. 在搜索框输入关键词，例如：
   - `G54`
   - `G71`
   - `M03`
   - `报警1001`
   - `铝件进给`
   - `对刀`
3. 系统会显示匹配结果。
4. 点击需要的条目，进入详情页查看完整内容。
5. 常用内容点击收藏，加入收藏夹。

### 使用技巧

- 不确定完整名称时，可以只输入一部分，比如 `粗车`、`坐标`、`报警`。
- 结果太多时，用分类筛选：G 代码、M 代码、报警、工艺、刀具。
- 编程时忘格式，直接搜指令号；现场报警，直接搜报警号。
- 详情页优先看“一句话解释”“图解说明”“常见错误”“相关案例”。

## 核心功能二：图文资料库 🖼

### 适合场景

很多数控知识只看文字很难理解，比如坐标系、刀具路径、对刀步骤、循环加工过程、机床面板按键、测量方法等。这类内容更适合用图片学习。

### 使用方法

1. 点击首页 **“图文资料库”**，或进入 **“图库”**。
2. 浏览图片分类：
   - 机床面板操作图
   - 刀具结构示意图
   - 坐标系示意图
   - 加工路径图
   - 测量检测方法图
   - 报警排查流程图
3. 点击图片查看大图和说明。
4. 查看关联知识点，必要时收藏。

### 学习建议

新手建议先看图，再看文字。比如学习 G02/G03 圆弧插补时，先看顺时针、逆时针路径图；学习 G54-G59 坐标系时，先看机床坐标和工件坐标的关系图。图看明白了，文字和程序格式就容易理解。

## 核心功能三：知识地图 🗺

### 适合场景

如果你不是临时查资料，而是想系统学习，就使用知识地图。它主要解决三个问题：从哪里开始学、当前知识属于哪一类、学完以后下一步看什么。

### 使用方法

1. 点击首页 **“知识地图”**。
2. 选择查看方式：
   - **学习路径**：适合新手，从基础到进阶。
   - **分类视图**：适合快速了解资料结构。
   - **树状视图**：适合查完整目录。
3. 点击任意阶段、分类或节点，进入对应内容。
4. 学习过程中可收藏重点内容，也可返回地图继续学习。

### 推荐学习路线

新手建议按下面顺序走：

1. 认识数控机床：了解机床结构、轴向、坐标、程序运行逻辑。
2. 机床基础操作：学习开机、回零、模式切换、程序调用。
3. 坐标系与对刀：重点掌握工件坐标、刀补、对刀流程。
4. G/M 代码基础：学习 G00、G01、G02、G03、M03、M05、M30。
5. 固定循环和加工案例：学习钻孔循环、车削循环、粗精加工流程。
6. 刀具与工艺参数：学习转速、进给、切深、刀具选择。
7. 报警排查与实战经验：学习常见报警、撞机风险、程序检查方法。

不要一开始就钻复杂宏程序。先把坐标、对刀、常用代码和加工流程学清楚，后面会轻松很多。

## 核心功能四：智能推荐系统 🤖

### 适合场景

很多数控知识不是孤立的。比如查 G54，可能还需要看 G55-G59、工件坐标系、对刀；查 G71，也可能需要看 G70 精加工、刀补、退刀量和常见错误。智能推荐就是帮你把相关知识串起来。

### 使用方法

1. 打开任意知识条目。
2. 在详情页查看 **“推荐内容”**。
3. 点击推荐项，跳转到相关知识。
4. 多浏览、多收藏后，推荐会更接近你的使用习惯。

### 推荐类型

- **同类扩展**：查看 G54，推荐 G55-G59。
- **前置基础**：查看宏程序，推荐变量、坐标、条件判断。
- **实战应用**：查看理论，推荐加工案例。
- **风险提醒**：查看循环指令，推荐常见错误和撞机风险。
- **操作关联**：查看坐标系，推荐对刀和工件原点设置。

## 使用建议

1. **先搜索，后分类**：老手查资料，搜索最快；新手学习，再用分类和知识地图。
2. **先看图，再看文字**：坐标、刀路、循环、对刀这类内容，图比文字更容易理解。
3. **收藏高频内容**：常用代码、报警、参数表建议收藏。
4. **学习路线不要跳太快**：先打牢坐标、对刀、常用 G 代码，再学循环和宏程序。
5. **现场操作注意安全**：查到程序或参数后，不要直接盲目上机。正式运行前应检查坐标、刀补、转速、进给、刀具号、工件装夹和安全高度。

## 常见问题

**Q：搜索不到想要的内容怎么办？**  
A：尝试换关键词。例如搜索不到“工件零点”，可以试试“G54”“工件坐标系”“对刀”。

**Q：搜索结果太多怎么办？**  
A：使用分类筛选，或把关键词写得更具体，例如从“循环”改成“G71粗车循环”。

**Q：图片看不清怎么办？**  
A：进入图文资料库后点击图片查看大图，步骤图建议横屏或放大查看。

**Q：内容能不能直接用于机床加工？**  
A：平台内容用于学习、查询和参考。实际加工前必须结合机床型号、系统版本、刀具状态、材料、装夹和安全高度确认。
