# 数控学习站配图库规划

## 1. 图片目标

目标不是一次性把 1000 张图片全塞到首页。

正确做法是：

- 先规划 1000 张图片的栏目体系
- 页面里按模块展示
- 需要时逐步补图

这样不会把网站直接拖慢。

## 2. 建议的 1000 张图片结构

### A. 新手入门图 120 张

- 坐标系方向图
- 回零流程图
- 对刀流程图
- 机床面板功能图
- 工件坐标系示意图
- 绝对值 / 增量值对比图

### B. G 代码图 220 张

- G00 / G01 运动轨迹图
- G02 / G03 圆弧方向图
- G17 / G18 / G19 平面图
- G41 / G42 刀补图
- G54-G59 工件坐标图
- G81 / G83 / G84 固定循环图

### C. 车床工艺图 160 张

- 螺纹
- 倒角
- 圆弧过渡
- 台阶轴
- 薄壁件

### D. 铣床工艺图 160 张

- 轮廓铣
- 开粗
- 精加工
- 钻孔
- 镗孔

### E. 刀具图 120 张

- 铣刀类型图

## 3. 页面上的用图原则

- 首页用缩略图和卡片图
- 详情页放步骤图、结构图、对比图
- 同一知识点至少配 3 张图
- 能动画表达的内容，优先做连贯系列图

## 4. 图片文件命名规范

建议统一命名：

- `beginner-coordinate-001.webp`
- `gcode-g02-arc-001.webp`
- `tool-insert-cnmg-001.webp`
- `alarm-servo-001.webp`

## 5. Gemini 出图建议

每张图尽量固定这些要求：

- 白底或浅米色工业教学风
- 线条清晰
- 大标题少字
- 核心区域高亮
- 手机竖屏阅读友好
- 不要复杂背景
- 不要写实车间大场景优先

## 6. 实施顺序

建议按这个顺序补图：

1. 新手入门
2. G00 G01 G02 G03
3. 对刀与坐标系
4. 刀补
5. 固定循环
6. 报警排查
7. 刀具识别
8. 图纸与量具
